# storefront —— 顾客前台 SPA

> 里程碑 M1b。

技术栈：Vue3 + Vite + TS + Tailwind v4（与 admin 对齐但独立包，顾客端体积敏感）。

## 多模板注册表（规划 §9.2）

- `templates/<name>/` 页面级覆盖，`?template=x` 预览。
- M1 只做 `classic`（列表/网格/大图三视图 + 分类导航两种样式，由 settings 驱动）。
- 移动端响应式同模板适配（不做独立移动模板）。

会员中心：余额/积分/订单/卡密取回（查询密码三重门）/推广码/工单/通知/分站申请入口。

> **状态（M1b 收口，2026-08-16）**：classic 基础版已落地——商品列表/详情 → 下单 → 支付（redirect/qrcode/params）→ 取货（订单号+查询密码三重门）→ 会员中心 v1（余额/积分）。技术栈用 Vue3 + Vite + TS + 纯 CSS（暂未接 Tailwind，M1 极简主题）。开发：`pnpm install && pnpm dev`（:9528，代理 /api → :8000）。

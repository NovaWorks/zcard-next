# Address metadata

Country and first-level region metadata downloaded from https://chromium-i18n.appspot.com/ssl-address/data/{country} on 2026-09-29. Google libaddressinput metadata format: https://github.com/google/libaddressinput/wiki/AddressValidationMetadata. No runtime network calls. Locality and district use free text where a local hierarchy is not bundled. Names are rendered with Intl.DisplayNames in the client. Review and refresh this snapshot when shipping destinations change.

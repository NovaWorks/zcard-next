# ZCard 2.0（zcard-next）

开源数字商品自动销售平台（发卡系统）——双向货源网络 + 单二进制交付。前台商城与管理后台全部内嵌在一个可执行文件里，拷贝上去就能跑。

> 前代版本：[ZCard 1.x（NovaWorks/ZCard）](https://github.com/NovaWorks/ZCard) · 本仓库为其完全重写的下一代版本

## 为什么重写 v2 —— 从 PHP 到 Golang

ZCard 1.x 采用 PHP 8.3 + Laravel 技术栈，功能完整且仍在维护；但在实际部署运营中，它的架构带来了一些难以根治的痛点。v2 使用 Golang 从零重写，针对性解决：

| 维度 | v1（PHP / Laravel） | v2（Go / 单二进制） |
|---|---|---|
| **部署** | PHP ≥8.3 + Composer + 多扩展 + PHP-FPM + Nginx + Supervisor + cron | **一个可执行文件**（前端页面全部内嵌），SQLite 起步零依赖 |
| **后台任务** | 队列强依赖——官方文档原话「队列不运行 = 订单已支付但永远拿不到卡密」 | Redis 可选：缺失时自动降级为进程内同步执行，**付了钱一定拿到货** |
| **升级** | 在线更新后需手动重启 PHP-FPM 与 Supervisor，版本回退靠手工 | 后台**一键在线更新**：自动备份数据库 → 下载验签 → 原子替换 → 自动重启；新版异常自动回滚上一版 |
| **数据库** | 必须 MySQL | SQLite / MySQL 8 / PostgreSQL 15+ 三档一套代码，随时平滑换库 |
| **功能互斥** | 分站与分销不能同时启用 | 架构上天然共存 |
| **资源占用** | PHP-FPM + MySQL 常驻，小内存 VPS 吃力 | Go 常驻内存低，1C1G 小鸡可流畅跑全套 |

### 为什么选择 Golang

- **单静态二进制**：`GOOS=linux GOARCH=amd64` 一条命令交叉编译，配合 `go:embed` 把管理后台与商城前端一并打进可执行文件——「下载一个文件」就是完整的安装包，天然适合发卡系统用户群的部署水平；
- **并发模型**：goroutine 承担上游同步、事件分发、队列消费、健康探测等全部异步工作，无需 Supervisor 常驻多个 PHP 进程；
- **内存与性能**：编译型语言 + 低 GC 压力，长时运行稳定，小规格服务器友好；
- **工程纪律**：静态类型 + `go test` + 架构守护测试（依赖方向、SQL 收口等由 CI 强制），配 wire/buf/ent 全量代码生成，多人协作与长期演进不易腐化；
- **自愈能力**：进程崩溃由 systemd 秒级拉起，在线更新失败自动回滚——运维成本向零逼近。

## 功能全景

### 商品与目录
- 树形分类：拖拽调整层级与排序、分类图标（emoji 图标库选择器）、递归子分类商品聚合
- 多规格 SKU：按规格定价/库存，会员价、库存继承（price_cents=0 继承商品价）
- 商品控件：自定义表单字段（下单时收集买家信息）
- 标签、会员商品组、批量上下架
- 商品评价：审核流 + 虚拟评价 + 前台展示开关

### 卡密库存
- 批量导入：CSV 预览 → 确认入库 → 支持撤销整批次；keyed-hash 去重防重复导入
- 批量导出（超管专属 + 审计）；单卡禁用/启用；靓号卡识别
- **AES-256-GCM 强制加密存储**（无关闭开关），后台查看完整卡密需二次确认并留审计记录
- 低库存阈值提醒、真实库存口径（上游代发商品实时联动上游库存，防超卖下单闸门）

### 订单与交易
- 游客下单 / 会员下单 / 开放 API 下单三通道；购物车多商品合并结算
- 订单超时自动取消（可配 TTL）；联系方式收集策略可配（不要求/手机/邮箱/QQ/任意）
- 取货页：订单号 + 密码随时查询，卡密明文展示（凭密码即取）
- 多币种：基础货币结算 + 展示层汇率换算，支付回调双向金额核对

### 支付收银台
- 六大支付驱动：**支付宝 / 微信 / Stripe / PayPal / 易支付（epay）/ USDT（EpuSdt，按链选择）**
- 一个渠道承载多种支付方式（自定义图标与描述），收银台按方式级选择
- 回调验签 + 幂等 + 金额核对；支付单补单（超管）；退款（审计）；钱包余额支付

### 履约交付
- 四种履约形态：本地卡密自动发货 / 固定内容（链接·兑换码直发）/ 人工发货 / 上游自动代发
- 付款 → 事件分发 → 自动交付全链路异步；交付失败可追溯（采购单 last_error 重试）

### 双向货源网络
- **下游拿货**：对接异次元（ACG-Faka）/ 独角数卡（Dujiao）/ 其他 ZCard 上游
  多货源连接管理、商品预览勾选导入、全量/增量/定时同步、价格库存上下架联动、
  类目映射、加价规则、封面采集本地化存储、采购单手动重试/转人工
- **对外供货**：开放 HMAC 签名 API，下游账户注册审核、api_key+secret、
  预存账本、商品级/SKU 级专属价、幂等下单、取消退款、回调通知

### 钱包与资金
- 余额 + 积分双账本；充值（满赠档位）、礼品卡批次兑换
- 提现：申请 → 审核 → 打款（手续费固定/比例，收款方式白名单）
- 手动调账（超管 + 审计）；积分抵现比例与上限可配

### 增长运营
- 三级分销佣金（按订单金额或利润计佣，确认收货期，支持逆向扣回）
- 会员等级：消费积分自动升降级、等级专属价、等级权益
- 优惠券 / 秒杀 / 促销活动；首页推荐位；顶部自定义按钮
- **分站白标**（商业版）：分站主绑定自有域名、独立定价、利润分账账本

### 客服与触达
- 工单系统：前台提交 + 内部备注 + 解决/关闭流转
- 通知中心：邮件 SMTP + 短信（阿里云/腾讯云/七牛）模板化通知、群发预估与取消
- 内容管理：横幅、文章栏目、站点公告（文本/图片/轮播）

### 商城体验（storefront）
- 多模板体系（PC/移动独立模板，主题市场式安装）
- SEO 三层闭环：robots/sitemap 动态生成 + vite-ssg 预渲染 + 爬虫动态渲染（内容改动实时生效零重建）
- 多语言、多币种切换；深度的移动端适配（收银台/订单/商品页大厂范式交互）

### 安全与权限
- RBAC：100+ 细粒度权限点，敏感操作超管专属（卡密明文/导出/资金操作）
- 审计三线：操作日志 / 安全日志 / 访问统计（PV/UV）
- 管理员 TOTP 两步验证、登录图形验证码、单 IP 待付款订单限流、风控黑名单
- 四把生产密钥（JWT×2 / 卡密加密 / 凭据加密）env 注入，密钥轮换工具

### 部署与在线更新
- **单二进制交付**：管理后台 + 商城 + 数据库内嵌，双架构（amd64/arm64）
- 三种安装方式：一键脚本（systemd 自愈 + Nginx 自动配置）/ 浏览器向导 / CLI
- **一键在线更新**：GitHub 直连 / 大陆加速镜像（自动探测竞速）/ 自建静态源三通道；
  ED25519 强制验签、流式哈希校验、原子替换、更新前自动备份数据库、
  新版健康检查不过自动回滚、版本历史面板（changelog 随签名清单下发）
- CLI 运维套件：`install / serve / migrate / admin / self-update / dbtest / reencrypt-cards`

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Go · Kratos v3（微服务框架）· Ent ORM · Atlas 版本化迁移 · wire 依赖注入 · protobuf 唯一真理源 |
| 前端 | Vue 3 · 管理后台 soybean-admin 定制（Naive UI + UnoCSS）· 商城 Tailwind v4 + vite-ssg |
| 存储 | SQLite（纯 Go 驱动）/ MySQL 8 / PostgreSQL 15+ 三方言一套代码；Redis 可选（队列/缓存，缺失自动降级） |
| 部署 | 单二进制（go:embed 双前端）/ Docker / systemd 一键脚本 / 宝塔进程守护 |

## 快速开始

```bash
# 方式一：一键脚本（Linux 推荐，自动 systemd + Nginx）
curl -fsSL https://raw.githubusercontent.com/NovaWorks/zcard-next/main/scripts/zcard-install.sh -o /tmp/zcard-install.sh
sudo bash /tmp/zcard-install.sh install --bin ./zcard-linux-amd64

# 方式二：手动部署（任意平台）
./zcard serve -conf configs     # 浏览器打开 http://IP:8000 → 安装向导

# 方式三：CLI 免浏览器
./zcard install
```

完整部署说明（启动管理、反向代理、域名与 HTTPS、在线更新）见 [doc/部署指南.md](doc/部署指南.md)。

开发者：

```bash
cd server && make init && make generate && make test && make run
```

## 工程纪律

- 金额一律 `int64` 分（`platform/money.Cents`），全仓禁止浮点存金额
- 卡密 AES-256-GCM 强制加密，永不落明文；keyed-hash 去重
- 跨模块只经 `port/` 窄接口 + outbox 事件通信，禁止 import 对方 biz/data（架构测试强制）
- `platform/*` 不依赖 `mods/*`；裸 SQL 只准出现在报表收口包
- 对外单号雪花 ID 不可枚举，内部主键自增，严格分离
- 三方言迁移线独立版本化；启动自动迁移，失败拒绝启动

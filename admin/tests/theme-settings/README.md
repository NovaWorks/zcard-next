# 主题自定义分组切换回归

## 已复现问题

长表单共用滚动容器。在「首页轮播」向下滚动，切换到「首页与商品」，再返回「首页轮播」，编辑器仍停留在表单中部，顶部来源、画幅和部分图片不在可视区域。切换本身没有清空配置值。

## 本次修复

`theme-settings-modal.vue` 在分组渲染完成后重置编辑器和移动端布局容器的纵向偏移。保留原有 values、条件显示和保存行为。

## 本地验证（2026-09-19）

使用实际 Vue ThemeSettingsModal + MediaField + Naive UI，注入 Yunfan 0.1.22 schema。接口、权限、素材选择使用本地模拟，不连接生产后台。

1. 1280×720：首页轮播向下滚动（修复前编辑器 scrollTop=1440），切换首页与商品再返回。修复后 scrollTop=0，来源选项重新进入可视区域。
2. 在第一张轮播填写未保存说明和点击链接，切换其他分组再返回：输入值保留，三个已配置图片元素均 complete=true 且 naturalWidth>0。
3. 390×844：滚动移动端外层布局（scrollTop=1688），切换分组再返回：布局和编辑器 scrollTop 均为 0，图片仍加载成功。
4. 手机填写说明，模拟保存草稿，关闭后重开：说明和图片保留。
5. `pnpm typecheck`、`git diff --check` 通过。

# 虎皮椒支付

后台「支付渠道」→「添加渠道」→「虎皮椒支付」。填写该支付渠道的 `APPID`、`APPSECRET` 后保存并启用。网关留空时使用 `https://api.xunhupay.com/payment/do.html`；也可以填写虎皮椒提供的备用网关完整下单地址或根域名。

微信和支付宝由虎皮椒 APPID 绑定的收款渠道决定。需要同时提供两种方式时，分别添加两个虎皮椒渠道，填写各自凭据，建议命名为「微信支付」「支付宝」。不要将 `plugins` 当作支付类型参数。

站点地址必须是公网可访问的完整地址。下单时系统自动发送对应渠道的回调地址（包含 `channel_id`），无需手工配置。APPSECRET 加密保存，后台不回显；编辑时留空保留原密钥。

## 收款行为

- 支持商品订单、会员余额充值和供货账户充值，金额为人民币，包含向顾客收取的手续费。
- 电脑直接显示虎皮椒返回的二维码图片；手机使用其支付链接。刷新、跨设备恢复支付时复用同一支付单和网关结果。
- 二维码有效期为五分钟。超过有效期再次发起时会提示更换支付方式或重新下单；迟到的真实付款仍由现有到账核对流程处理。
- 请求、下单响应及异步回调按官方 MD5 协议签名/验签；回调再核对本地支付单、渠道、金额和币种。重复成功通知不会重复发卡或入账。
- 仅 `OD` 状态确认收款。其他已验签状态只应答 `success`，不作为付款或本地退款完成凭据。
- 本次不提供网关主动查单补单及原路退款；需要在虎皮椒后台核对/操作。现有站内退款流程保持原有能力。

使用现有 `qrcode` / `redirect` 载荷，无新增前端 API 类型。自定义主题的 `qrcode` 渲染器应将 `code_url` 中的 HTTP(S) 图片地址直接作为图片展示，不能把图片地址再次编码成二维码。

## 验证与参考

本地测试覆盖模拟网关下单、独立签名向量、错误响应/伪造回调、金额不符、重复发卡及充值通知、后台密钥脱敏和留空保留、桌面/手机支付呈现与缓存复用。真实商户下单、支付到账及公网回调需部署后另行验收。

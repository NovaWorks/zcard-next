# 后台上游来源定位

商品列表显示当前货源；订单项保存下单时来源；普通卡密采购单保存实际采购时来源。有采购单时以采购记录为准。快照不含 API 凭据，只经管理接口读取。

渠道 settings 支持 `website_url`（与 API 不同的网站地址）与 `product_url_template`。占位符：`{base}` 网站地址、`{code}` 原始编码、`{product_id}` 商品编号、`{sku_id}` 规格编号。编号按路径或查询参数编码。ZCard 默认 `/product/{product_id}`，萌次元默认 `/item?id={product_id}`；未核实路由的渠道提供网站与编号。萌次元 `12~52` 拆分为商品 `12` 和规格 `52`，打开商品页后需自行核对规格。

快照保留当时链接。旧采购单使用原采购连接和编码配合当前渠道设置推算，并标记“按原编号及当前渠道推算”；连接缺失或订单无历史记录时不读取当前商品映射猜测目标。此时保留能确认的编号，联系原上家核对。

采购详情同时展示上游单号、原请求号、追踪号和错误。打开商品链接只是浏览，不会再次采购。超时或扣款不明时应先核对原单，再决定人工拿货及补发。

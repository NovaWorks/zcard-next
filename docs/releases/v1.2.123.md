# ZCard v1.2.123

发布日期：2026-11-23

## 在线服务参考价和商品说明

- 商品列表、详情接口为已配置定价的在线服务提供人民币参考金额及对应数量，供已适配的前台展示。参考价按本站当前汇率和零售加价规则计算，不公开上游费率，也不把服务商品当作零元卡密。
- 参考数量遵守服务最低数量、最高数量和步长。定价未配置、服务不可购买或计费未核实的商品不提供参考价；历史 SKU 映射不会覆盖服务商品的独立定价规则。
- 参考价使用已导入的服务资料，不因公开浏览创建报价、采购或扣款。填写实际购买资料后，仍须确认本次总价；参考价不锁定上游价格，不改写历史订单。
- 19csn 服务目录同步商品说明，导入时清理不安全内容。上游未返回说明时不清空已有说明；已有商品可重新同步以补齐服务资料。

## 萌次元购买表单兼容

- 修复萌次元商品保存了上游表单规则后，报价或下单被误判为不支持传递资料的问题。没有附加字段的合法表单也能正常报价，报价不会创建订单。
- 付款前继续校验上游必填、长度和格式规则，按订单项保存原字段标识及填写内容。货源或商品绑定变化后，拒绝将历史填写资料转发给新目标。
- 独角兽现有表单行为继续保留，其他未适配货源不会自动获得表单转发权限。

## 升级说明

本版无新增数据库迁移。备份数据库、配置和上传文件，保留原加密密钥，配套更新服务端、后台和内置商城后重启。独立前台展示参考价需要支持相应商品字段；实际购买继续使用独立的服务总价报价流程。

本版包含此前未发布的服务参考价、19csn 描述同步，以及新增的萌次元表单兼容修复。v1.2.122 的按购买数量确认库存和明确拒单余额退款处理继续保留。

提供 Linux amd64 / arm64 完整程序、SHA256 校验、ED25519 签名更新清单及双架构 Docker 应用和配套更新器。发布不代表客户站点已经升级；真实上游采购、交付和资金处理仍需分别验收。

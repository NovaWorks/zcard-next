📦 ZCard 众卡 v1.2.119 更新日志
📅 发布日期：2026-11-20

🔌 新增萌次元上下游对接
• 上游渠道新增“萌次元 mcy-shop”，填写 OpenApi 对接 ID、密钥和网站根地址即可连接。
• 支持商品、图片、说明及多 SKU 导入，逐规格读取账号拿货价，按所选规格查库存并下单。
• 下游账号新增萌次元协议，对方可通过“异次元 V3 / MCYShopV3”货源插件接入；同时提供 OpenApi 兼容接口。
• 下游继续遵守审核、余额、供货价和 IP 白名单，同一订单重复提交只扣款一次。

🛠 采购结果处理
• 下单后遇到超时、异常响应或交付数量不符时，转人工核对原上游订单，避免重复采购或已扣款后自动退款。
• 文字库存保持未知，不冒充无限库存。尚未核实独立查单、自动退款和回调能力。

📌 升级与配置
本版包含 MySQL 协议字段迁移，启动时自动执行。升级前请备份、保留原加密密钥，配套更新服务端、后台和商城。
上游需启用 OpenApi 插件；对外供货目前仍限人民币、无本地 SKU 的本地卡密商品。
本地契约及 MySQL 测试已通过，尚未与真实运营的萌次元站联调。

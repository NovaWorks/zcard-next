# ZCard v1.2.115

## 复制商品

- 后台「商品管理」的商品行新增「复制」。分类、售价、成本、封面、图集、描述和适用的运费设置会预填到新商品表单，保存前可以修改。
- 副本默认下架，首页推荐关闭。库存、SKU、下单控件、货源和直发内容需要单独配置，检查后再上架。
- 支持普通虚拟商品和实体商品。动态报价的社交服务和接码渠道继续从货源管理添加。

## 实体运费到付

- 编辑实体商品时，可在「基础信息 → 运费方式」选择「运费到付」。快递在买家收货时收取运费，线上结算仅计入应在线支付的金额。
- 内置商城在商品详情、结算和订单详情提示运费到付。混合下单时，固定运费仍按原规则计入线上金额。
- 订单保留下单时的到付设置。后台按商品项标记到付，发货时请向承运公司选择运费到付。

## 升级说明

本版无需新增数据库迁移。请使用完整发行包同步更新服务端、管理后台和内置商城。独立安装的第三方主题需要适配商品的 `shipping_mode: "collect"` 及结算和订单项的 `shipping_collect` 提示。

# ZCard v1.2.108

发布日期：2026-10-03

## 实体商品与库存设置

- 商品属性独立选择“虚拟”或“实体”，后台列表正确显示实体商品，不再显示为卡密。分类只用于商品分组；已保存商品如需更换属性，请新建商品。
- 实体商品提供“管理库存”“前台显示库存”“前台显示销量”三个独立开关。关闭库存管理可不限库存接单，并隐藏商品及规格库存输入和商城库存展示；原库存数量保留，重新开启前需核对。
- 商品库存、销量显示同时遵守商城全局开关，关闭后不再显示相应数据。实体表单隐藏卡密、去重等虚拟交付设置。

## 实体订单与国际地址

- 纯实体订单无需设置查询密码。会员通过账户查看订单；游客填写有效邮箱，保存订单访问链接，用于支付、物流查询及确认收货。
- 换设备或遗失链接时，可用下单邮箱验证码恢复访问。恢复后旧链接失效；虚拟商品、混合订单和历史查询密码继续按原规则使用。
- 收货地址支持地址第一行、选填的地址第二行、郊区或城市、州／省／地区及邮政编码，按所选国家调整字段顺序、必填项和格式，兼容已有地址。
- 实体订单展示配送和包裹进度，隐藏卡密取货流程。取消、退款及退货按下单时的库存记录处理，之后切换库存管理不会让旧订单重复增加或遗漏库存。

## 升级与验证

本版包含 SQLite / MySQL / PostgreSQL 数据库迁移。请先备份数据库、配置及上传文件，保留原加密密钥，使用完整发行包更新服务端、后台与商城，重启后检查迁移日志并刷新浏览器。已有商品属性、库存及库存显示设置保留；新增库存管理和销量显示默认开启。

内置商城已适配上述功能。商业独立 Gift 主题及其他单独安装的主题不随主程序发布，需分别更新兼容的主题包。游客邮箱找回需在后台配置可用的 SMTP 邮件服务。

本地验证已通过后端回归、三种数据库历史升级与重复迁移、真实 MySQL / PostgreSQL 库存及退款并发回归、前后台类型检查和构建，以及隔离环境中的实体下单、支付回调、发货、收货与邮箱恢复流程。本地验证不代表客户生产站点已升级或真实支付渠道已验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

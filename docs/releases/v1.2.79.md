# ZCard v1.2.79

发布日期：2026-09-24

## 商品锁定

- 商品列表新增锁定、解锁与锁定状态筛选。锁定后仍可查看，资料、价格、上下架、分类、SKU、下单控件等维护操作被阻止，无法删除；已下架商品同样受保护。
- 全选自动跳过锁定商品，批量上下架、修改分类和图文内容在服务端再次检查锁定状态，返回实际处理与跳过数量；批量删除保留逐项失败原因。
- 上游资料、价格及上下架同步跳过锁定商品。手工卡密导入、撤销、启停及虚拟评价新增也受保护；正常下单、实际库存预占释放、发货和真实评价审核继续运行。
- 商品锁定使用独立权限和审计记录；并发锁定与维护串行处理，过期锁定状态提交返回冲突，避免旧页面覆盖新状态。

## 分类内置顶与推荐

- 商品管理选择分类后新增「置顶与推荐」入口，分类管理也可进入。可选择本分类及全部子分类的商品，设置仅在当前分类生效。
- 置顶与推荐可分别设置，支持拖动、上移、下移、移到最前；点击「保存设置」后生效，电脑和手机均可操作。
- 置顶仅影响商城当前分类的综合排序，价格、销量和最新排序仍遵守访客选择；分类推荐标签与首页推荐独立。
- 下架、隐藏分类和移出分类范围的商品遵守原有可见性规则，后台显示未展示原因。包含锁定商品的分类不可跨父级移动或合并，防止绕过商品保护。
- 保存冲突或失败保留草稿，关闭或离开页面提醒未保存修改。数据库先排序再分页，避免分页后置顶造成商品遗漏或重复。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 增量迁移，新增商品锁定字段和分类商品运营配置表。升级前备份数据库、配置和上传文件；旧商品默认未锁定，原有首页推荐不变。后台与内置商城随完整发行包一起更新，升级后刷新浏览器。

独立第三方主题需接入 `category_recommend` 字段显示分类推荐标签；分类列表 API 已包含置顶排序。商品锁定不等于暂停销售，如需暂停销售，请先下架再锁定。解锁后恢复原有维护权限，后续上游同步按原规则执行。

为避免共享封面或事务回滚后丢图，上游同步不再提前删除旧采集封面文件；旧文件可能继续占用磁盘，本版不新增自动垃圾回收。

已完成后端全量测试、相关竞态检测、后台与商城类型检查和构建、桌面及手机浏览器流程验证，以及三种数据库的历史数据升级验证。MySQL/PostgreSQL 真库覆盖并发锁定与分页排序。测试为隔离环境验证，不代表客户服务器已安装升级。

Linux amd64 / arm64 完整发行包内置后台与商城，附 SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.79 bash deploy/docker-install.sh` 更新。

# ZCard v1.2.96

发布日期：2026-09-30（北京时间）

## UPAY PRO 多币种与选链支付

- 一个 UPAY PRO 渠道现在可以勾选多个币种与网络，支持 USDT、USDC 多链及 TRX，共 10 种组合；无需为每条链重复创建渠道。
- 商品付款、会员余额充值和供货账户充值均展示已启用的组合。顾客选择后，按该组合创建上游订单并进入对应收银台；服务端拒绝未启用选项，多选配置下不再静默使用默认链。
- 后台支持多选保存与回显，至少保留一个选项。原单选配置兼容原值，升级不会自动开启其他网络；原有支付链接继续按原网络处理。
- 支付记录、费用报价和收银台复用按币种与网络区分。同一网络重复点击复用原链接，切换网络使用独立支付单，切回后复用原网络的有效链接。
- 上游请求进行中或结果未知时禁止换链绕过原请求。多个网络都收到款时只履约或充值一次，额外到账保留记录并进入待核对。

## 升级说明

本版无新增数据库迁移。请先备份数据库、配置及上传文件，使用完整发行包同步更新服务端、后台和默认商城，完成后刷新浏览器。

在支付渠道的 UPAY PRO 配置中勾选需要提供的币种与网络，只开启已在 UPAY PRO 配置钱包和汇率的组合。存在未确认支付时仍需保留原渠道配置，先处理在途支付再调整。

独立第三方主题需展示渠道接口返回的支付方式，并把顾客选择的方式提交给费用报价及付款接口；多选时不能省略选择。GM Pay、BEpusdt 保持各自独立协议。

继续支持 v1.2.95 的 Docker 后台在线更新。已接入升级助手的官方 Compose 部署可在后台检查更新；尚未接入的 Docker 用户可在原部署目录执行 `ZCARD_VERSION=v1.2.96 bash deploy/docker-install.sh --online`。发布版本不会自动升级客户站点。

已通过后端全量测试、UPAY/BEpusdt 并发检测、前后台类型检查及构建，以及桌面和手机浏览器的多选保存、旧配置回显、选链与跳转验证。支付测试使用本地模拟网关，真实链上付款需部署后小额验收。

发行包内置后台与默认商城，提供 Linux amd64 / arm64 程序、Docker 双架构镜像、SHA256SUMS、ED25519 签名更新清单和 Docker 镜像清单。

# ZCard v1.2.126

发布日期：2026-11-23

## ZCard 货源规格与购买资料

- 修复从新版 ZCard 供货端导入商品时丢失原生规格的问题。同步保留各规格的名称、供货价格和库存，下单、库存及实际数量检查使用所选规格。
- 支持接收、展示和传递供货端声明的购买资料。必填项、类型、选项和长度限制随商品同步；刷新商品报价时继续保留规格及填写规则。
- 提交采购时携带冻结的上游规格和购买资料；供货端明确拒绝无效规格或资料时正确识别，避免把规则错误当作普通网络问题。
- 同步跳过已停用规格，并保留完整规格目录标记。未知库存继续按实际购买数量确认，不改成无限库存。

## 升级说明

本次没有新增数据库迁移。升级完整程序后重启，并重新同步相关 ZCard 商品。升级前备份数据库、配置和上传文件，保留原加密密钥。

多规格和购买资料转供需要供货端同时支持 `card_purchase.v1`；只升级开源版不会自动开启尚未更新的供货端能力。普通卡密及既有服务协议继续保留。Market 供货端的配套修复另行发布，本版不包含私有适配器或其后台代码。

提供 Linux amd64 / arm64 完整程序、SHA256 校验、ED25519 签名更新清单及双架构 Docker 应用和配套更新器。

本地验证使用两个独立程序和数据库、模拟上游，覆盖付款、规格与资料传递、回执及异常恢复；不代表真实上游付费交易或客户站点已经升级。

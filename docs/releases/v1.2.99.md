# ZCard v1.2.99

发布日期：2026-10-01

## 独立短信接码渠道商品

- 每条供货端发布的接码渠道只采集一个商品，重复采集与同步更新原商品，无需为国家、平台创建明细商品或 SKU；采集时沿用现有零售加价配置。
- 默认商城新增专用接码商品页，按国家与服务动态加载报价和库存；会员确认最新零售价后使用 CNY 余额购买，同页查看号码、验证码、短信正文及历史会话，按供货能力取消或结束接码。
- 后端保存限会员、限商品、限期限的固定报价，零售售价与供货成本分别记账。建单、付款或取消响应丢失时，继续确认原订单与原操作，避免重复采购、重复扣款或重复退款；核对供货全额退款后按零售剩余实付退款。
- 成本、供货报价标识及供货凭据不返回买家；支持会员直接访问隐藏渠道商品，游客及其他站点身份仍受可见性限制，会话响应禁止缓存。

## 兼容与问题修复

- 后台渠道商品编辑显示实时定价说明，不再要求填写固定售价、SKU 或下单控件；兼容已有明细接码商品。
- 渠道商品跳过聚合库存查询、库存同步、低库存巡检与普通库存自动上下架，避免误报库存失败及挤占普通商品巡检；实际报价仍校验可购库存。
- 排除没有接码任务的过期未付款订单，避免历史号码列表整页失败；取消与结束按精确操作回执确认，旧回执不覆盖新操作。
- 修复切换国家后服务选项丢失，账号切换或退出后旧异步结果写入页面等问题，并调整电脑和手机的专用接码页面。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 增量迁移，新增商品类型及零售接码报价表。请先备份数据库、配置和上传文件，保留原加密密钥，同步更新服务端与内置后台、商城，并刷新浏览器；数据库迁移后回退程序前需核对数据兼容性。

接码新购由默认关闭改为默认开启，无需设置环境变量；显式设置 `ZCARD_SMS_SALES_ENABLED=false` 可暂停新购，已有订单仍继续查单、操作和退款。渠道商品需供货端支持 `sms_channel_purchase.v1` 及对应动态选项、报价与采购接口；仅升级本客户端不会为供货端增加这些能力。

接码购买限定主站登录会员、CNY 余额、单件独立订单，暂不支持游客、外部支付、购物车、SKU、优惠券、积分和营销返佣。独立第三方主题需适配新商品类型及接口。

发布验证已通过 Go 全量测试、`go vet`、MySQL 8 / PostgreSQL 16 全量集成测试、前后台类型检查与生产构建、fullstack 内嵌资源检查，以及 390px / 1440px 隔离 API 页面测试，覆盖国家切换、最新报价、响应丢失恢复、短信展示与零售退款。

发行包内置后台与默认商城，提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。本地协议、数据库和页面测试不代表真实供应商付费取号、实际收码及资金闭环已验收；版本发布不代表客户站点已自动升级。

📦 ZCard 众卡 v1.2.121 更新日志
📅 发布日期：2026-11-21

🔌 新增 19csn 服务渠道
• 后台选择“19csn（服务渠道）”，填写网站地址和 API Key，即可测试连接、读取余额及导入服务。
• 支持普通服务单次投放、自定义评论，填写资料后确认本次总价，再使用会员余额付款。
• 订单可查看服务进度，按服务能力申请取消或补量。
• 测试连接显示实际账号币种，整单报价保留上游小数精度，避免重复换汇。

🛠 采购与结算保护
• 下单或操作结果不明时保留待核对状态，不自动重复采购。
• 部分完成、取消不等于退款到账，不按剩余数量推算退款。
• 套餐、订阅和循环投放的计费尚待核实，暂不开放。

📌 升级与配置
本版无新增数据库迁移。备份数据、保留原加密密钥，配套更新程序、后台和商城并重启。

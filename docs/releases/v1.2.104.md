# ZCard v1.2.104

发布日期：2026-10-02

## 实体配送与后台发货

- 后台“待发货”同时列出实体快递配送和人工交付，按当前站点筛选并显示剩余待寄数量；实体订单直接进入快递配送面板，发货后自动刷新并移出列表。
- 多商品订单按订单分页，修复商品项数量影响下一页判断的问题；缺少订单详情权限时显示明确提示。
- 包裹、退款明细和退货操作显示商品规格；前后台分别展示购买、取消、寄出、收到和退回入库数量，避免部分取消后数量难以核对。
- 退货入库记录包含商品项、入库数量及验收原因；修复长中文商品名称使事件超过字段限制、导致合法入库失败的问题。

## 支付授权与优惠券

- 支付报价和创建支付统一验证站点归属及订单访问权限；钱包支付必须由登录的订单所属账户操作，查询密码或报价标识不能授权扣取他人余额。
- 优惠券核销改为原子条件更新，同一张券跨商品并发下单仅一笔成功，失败订单整体回滚。
- 商品及运费全部退款、所有商品数量全部取消且从未交付时返还有效券；部分退款、已寄出、虚拟商品已交付及过期券不返。支付手续费单独处理，零应付订单全部取消也可返券。
- 返券按原使用订单校验，旧退款重放不会清除新订单的优惠券占用；返券失败会回滚退款事务。
- 优惠券页面修正折数显示，例如 9500 为 9.5 折、9850 为 9.85 折；过期券不列为可用，长期券和读取失败状态明确显示。

## 游客购物车与界面

- 游客可正常打开购物车，显示真实商品规格，优惠与运费在结算时核算；结算失败或关闭地址弹窗后恢复按钮，只清理本次提交的商品。
- 修复零价字段被省略时，付费商品与零元赠品混合的购物车合计显示为零的问题。
- 国内及国际手机号均进入联系方式查单，保留订单号与查询密码直接查询。
- 默认首页、品牌条及页脚文案适配虚拟交付和实体配送，保留商户自定义设置；后台促销门槛说明明确按优惠后的单件商品金额判断，运费不计入。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置及上传文件，保留原加密密钥，使用完整发行包同步更新服务端、后台与商城，并刷新浏览器。从旧版本升级仍需执行已有累积迁移；独立第三方主题需适配新增数量及待发货分页字段。

历史无查询密码的会员订单仍可由登录本人支付；历史无查询密码的游客订单缺少可验证身份，支付入口将拒绝发起支付。余额支付要求订单所属账户登录，不能凭查询密码扣取他人余额。

验证覆盖 Go 全量测试、go vet、支付授权与优惠券/退款/履约竞态回归、真实隔离 MySQL / PostgreSQL 同券跨商品并发及返券验证、前后台类型检查和生产构建、fullstack 内嵌资源检查。390px 手机与 1280px 桌面浏览器验收覆盖游客混合购物车、优惠券、运费、国际手机号查询及实体 SKU 的取消、发货、收货和退回入库。

浏览器使用隔离测试库和合成账号，零元订单用于验证支付后的履约链路，不代表真实支付渠道、物流或客户生产站点已验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

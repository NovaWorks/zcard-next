# ZCard v1.2.128

发布日期：2026-11-23

## 上游商品直达链接修复

- ACG 商品的接口对接码与网页数字 ID 分开保存。导入或重新采集取得有效网页 ID 后，后台可直接打开上游 `/item/数字ID` 商品页；库存、报价和拿货继续使用原接口对接码。
- 后台分别显示和复制网页商品编号、对接码及规格编号。旧记录不再把对接码标为可在网页搜索的商品编号。
- 新订单保存当时的网页商品 ID，采购任务沿用原连接和原对接码对应的订单记录；换源或删除商品后不会跳到当前绑定的另一个商品。
- 缺少、无效或未返回网页 ID 时保留网站入口并明确提示，仍支持渠道中已配置的商品链接模板。历史订单缺失网页 ID 时不会猜测或自动回填链接。

## 升级说明

本版增加 SQLite / MySQL / PostgreSQL 的商品导航元数据字段。升级前备份数据库、配置和上传文件，保留原加密密钥。升级后刷新后台，对已有 ACG 商品执行重新采集或上游商品信息同步，以获取网页商品 ID；仅刷新库存不会补齐此字段，无需删除商品或重建映射。

上游必须在接口中提供与网页对应的数字 ID，才能生成默认直达链接；自定义网站路由可继续使用渠道商品链接模板。缺少原始网页 ID 的历史订单仍需按采购单号向上游核实。

本版不改变 ZCard 供货模式的商品标识与报价契约，私有上游导航信息仅供本站管理员查看。独立付费主题不包含在主程序发行包中。

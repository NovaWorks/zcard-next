- 两个独立站点使用独立配置、数据库、密钥和钱包，通过真实 HTTP API 验证供货版转给开源版的链路，上游付费服务使用本地模拟器。
- 19csn 和 GainsFollower 各验证 12 种服务目录及 6 种下单场景：普通数量、自定义评论、已确认固定计费套餐、部分完成退款、明确拒单退款、提交结果未知。退款只入账一次；未知订单核对后没有第二次采购。
- 商品介绍从供货版保存到下游成功；订单详情读回原始链接、数量和评论，已完成订单仍可查看。19csn 的三种无效评论输入在付款前拒绝，两个钱包余额不变。
- 两仓 server 全量 Go 测试和 go vet 通过。供货版 market 模块全量测试通过；供货版插件资源预算用例在低负载下单独通过。
- 管理后台及商城生产构建、fullstack 嵌入检查通过；此前桌面和手机订单 UI 回归通过。Linux amd64 / arm64 四个实际发行程序均在隔离容器中执行并核对版本。
- 两版各自容器通过启动、SQLite 网页安装、前后台资源、更新保护、容器重建，以及配置、密钥和上传文件保留检查。

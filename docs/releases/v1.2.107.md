# ZCard v1.2.107

发布日期：2026-10-02

## 上游商品详情图片

- 导入商品和采集同步统一处理详情中的图片，按上游地址解析相对路径、根路径及协议相对路径，并兼容常见懒加载图片字段。下载成功后改为本站上传目录地址，减少详情页图片指向本站错误路径的问题。
- 封面使用同一套 URL 解析，修正带目录的上游地址和相对图片路径组合；下载失败保留完整上游地址，下一次导入或采集可重试，不将临时失败永久缓存。
- 图片下载只接受 HTTP / HTTPS，校验内网地址及重定向目标，继续限制图片类型、体积与请求时间；安全检查或下载失败不阻断商品导入。
- 拒绝图片路径返回的 HTML 错误页，避免破图被错误保存并缓存；连接阶段复核并固定已验证的 IP，防止 DNS 变化绕过内网地址检查。
- 保留已锁定商品及受保护的详情、封面。价格、库存和上下架等轻量同步继续只更新各自范围，不重写商品详情。

## 独立云帆主题 0.1.32

云帆手机表单控件字号至少为 16px，并保留更大的商户字体设置，处理小字号输入可能触发的 Safari 聚焦放大和页面偏移隐患。桌面样式、用户缩放、金额换算规则及财务记录保持原行为。

云帆为独立安装主题，需另外上传 `yunfan-0.1.32.zip`；升级主程序不会自动替换已安装主题。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置及上传文件，保留原加密密钥，更新完整发行包并重启服务端。从旧版本升级仍需执行已有累积迁移。

已有商品中的破图不会在升级时自动重写。升级后执行一次货源采集同步，或在导入页面重新导入相应商品以更新详情；受保护详情需由运营核对原内容，确认允许上游覆盖后解除保护再同步。无需删除货源、商品映射或历史订单。

Go 全量测试和 go vet 通过；回归覆盖相对图片 URL、常见懒加载字段、本地采集、失败重试、下载限制与受保护字段。云帆生产构建和主题包检查通过；320 / 390 / 768 / 1440px 视口与 12 / 15 / 18px 字体共 12 组模拟接口检查通过，页面未出现横向溢出，手机输入字号符合下限，桌面及金额展示保持原行为。

以上验证不代表全部真实上游图片已恢复，也不代表 iPhone 实机或客户生产站点已验收；具体上游图片不可用、权限及防盗链仍需按实际响应核对。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

📦 ZCard 众卡 v1.2.112 更新日志
📅 发布日期：2026-10-25

🗂 按规格导入卡密
• 后台导入可选择具体规格，支持预览、去重、按规格查询和导出；商品与规格页可快捷进入导入。
• 有规格商品必须明确选择目标，无规格商品继续使用默认池；不适用卡密的发货方式会显示原因。
• 批次记录原导入目标，同时展示当前卡密分布。

🔄 历史库存与批次保护
• 默认池历史卡密可先预览，再分配到同商品的具体规格，保留原批次来源；排除已占用、已用及抽奖引用等卡密。
• 撤销按整个原始批次处理剩余可用卡密，保留预占、已用和禁用卡密，库存变化须重新预览。
• 有库存、订单、抽奖或发货来源引用的规格会阻止删除。

🛡 下单与日志完善
• 可售库存按有效规格池统计，积分兑换先选规格，规格售罄不会取用其他规格卡密。
• 旧版原生供货、ACG、独角数卡接口暂不支持多规格新单，在扣款前拒绝；历史订单查询与重放保持兼容。
• 导入卡密与预览样例不进入操作审计和运行日志。

📌 升级提醒
本版新增三种数据库的批次目标字段迁移。请先备份、保留原加密密钥，配套更新前后台并重启，确认迁移成功。
旧批次保留「历史未记录」，不会自动归属；有规格商品的历史默认池库存需人工预览分配。旧导入客户端需为有规格商品传入 sku_id。
本地全量后端、并发、前后台构建、桌面与手机浏览器回归，以及真实 MySQL/PG 履约、锁竞态和 v1.2.111 升级 HTTP 验收通过。客户站点升级、第三方主题和实际交易需分别验收。
支持 Linux 双架构发行包与 Docker 后台在线更新，版本发布不代表客户站点已升级。

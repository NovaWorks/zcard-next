# ZCard v1.2.89

发布日期：2026-09-28（北京时间）

## 新增虎皮椒支付

- 支付渠道新增「虎皮椒支付」，支持商品订单、会员余额充值和供货账户充值。
- 配置对应的 APPID、APPSECRET 即可接入，支持自定义网关；微信、支付宝按各自 APPID 分别添加渠道。
- 电脑直接展示虎皮椒二维码图片，手机跳转支付链接；刷新或跨设备恢复时复用原支付单与网关结果。
- 下单请求、下单响应和异步通知按官方协议签名/验签，到账继续校验支付单、渠道、金额与币种；重复通知不会重复发卡或入账。
- 后台密钥加密保存、不回显，编辑时留空保留原值。

## 充值页面修复

- 修复供货账户充值未解析 JSON 支付载荷，导致二维码或跳转地址不正确的问题。
- 虎皮椒二维码图片直接展示，其他二维码内容在本地生成，不再发送到外部二维码服务。

## 升级说明

本次新增功能不包含数据库迁移。请使用完整发行包同步更新服务端、后台与商城，并刷新浏览器。微信与支付宝应分别创建渠道；站点地址需要公网可访问，以接收付款通知。二维码有效期五分钟，过期后请更换支付方式或重新下单，已付款请等待到账通知。

自定义主题需支持将 qrcode 载荷中的 HTTP(S) code_url 作为图片直接显示，不能把图片地址再次编码成二维码。本次接入不包含虎皮椒主动查单补单和原路退款，这两项仍需在虎皮椒后台核对或操作。

验证覆盖支付模块回归、下单与回调签名、错误金额和伪造通知、重复发卡和充值通知、后台配置与密钥保存、桌面及手机支付入口；前后端类型检查、构建和支付静态检查通过。使用模拟网关，未进行真实商户付款或公网回调验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.89 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已经安装或重启。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.89

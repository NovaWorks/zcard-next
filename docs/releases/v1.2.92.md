# ZCard v1.2.92

发布日期：2026-09-30（北京时间）

## 后台白屏与登录续期

- 修复从商品管理切换菜单后内容区白屏、刷新才恢复的问题；内容渲染异常时提供重试入口。
- 修复登录令牌过期后请求不能正确续期的问题。并发请求共享一次续期，旧请求不会重复刷新令牌，每个请求最多重试一次；续期失败返回登录页。
- 修复普通 HTTP 环境缺少 randomUUID 时实体配送面板或下单报错，同步兼容渠道导入和抽奖操作的请求标识。

## 实体订单与退款保护

- 实体退款和取消增加请求幂等保护：同一请求重试返回原记录，不重复回补库存、退款入账或产生通知事件；同一请求键改动内容会被拒绝。
- 修复零金额部分取消重试后重复取消数量、重复回补库存的问题。
- 人工补发拒绝已取消或已退款的虚拟商品；替换卡密时正确释放历史无规格预占库存。
- 已全额退款但包裹已寄出的订单允许更正快递单号，同时保持退款终态，禁止重新发货和修改收货地址。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 的退款请求键迁移。升级前备份数据库、配置及上传文件，同步更新服务端、后台与商城，检查迁移日志并刷新浏览器。SQLite 会重建退款表并保留历史记录。

旧后台或自定义客户端进行零金额取消时必须携带新的 request_key；未携带会明确拒绝并提示刷新。已有有金额退款接口保留兼容，建议客户端同时适配请求键保护。普通 HTTP 的兼容修复不代替生产环境的 HTTPS 配置。

已通过后端全量测试、履约与支付竞态检测、前后台类型检查和构建、真实 MySQL/PostgreSQL 迁移与并发取消测试，以及独立浏览器菜单切换、会话续期和 HTTP 实体结算验收。测试未执行真实付款或快递发货。

发行包内置后台与商城，提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.92 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已自动升级。

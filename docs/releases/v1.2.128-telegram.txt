ZCard v1.2.128 已发布

修复 ACG 上游商品无法直接定位的问题：网页数字 ID 与接口对接码分开保存，同步取得网页 ID 后可直接打开 /item/数字ID 商品页。后台分别提供商品编号、对接码和规格编号复制。

新订单保留原商品链接，换源后仍可核对原采购商品。历史记录缺少网页 ID 时明确提示，不再引导拿对接码到网页搜索。

本版有数据库迁移，请先备份并保留原密钥。升级后对已有 ACG 商品重新采集或同步商品信息；仅刷新库存不会补齐网页 ID。上游未提供网页 ID 的商品及缺失该信息的历史订单，仍需向上游核实。

详情及下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.128

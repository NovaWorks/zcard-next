# ZCard v1.2.84

发布日期：2026-09-26（北京时间）

## 旧版货源导入兼容

- 修复部分异次元货源报价接口返回 HTTP 200 + HTML 404 时，被误报为限流并反复重试、降速的问题。
- 确认报价接口不存在后，兼容旧版普通商品与分类规格的账号报价；保留价格精度、完整规格和账号隔离校验，不使用目录展示价替代失败报价。
- 兼容单品接口返回分类树的格式，精确匹配商品后查询库存；缺失字段、错误商品、重复商品及损坏库存分别处理。
- 旧版多规格库存逐规格查询并汇总，不再把默认规格库存当总库存；任一规格失败或数值溢出时保留待确认状态。
- 缓存当前渠道实例的接口能力，减少重复请求不存在的接口；真实限流、鉴权失败、服务异常和无效报价不会触发错误降级。
- 规格报价不完整、现代与旧版报价混用时停止该商品处理；旧版无法可靠支持的组合附加规格仍保持失败，避免错价。

## 购物车登录状态

- 修复购物车缺少登录身份时返回普通服务器错误的问题，统一返回 HTTP 401 与明确的重新登录提示，覆盖查询、添加、修改及删除操作。

## 商用许可与出处说明

- 补齐标准 MIT 许可证，明确允许商用、收费服务、修改和销售软件副本，不要求公开修改后的源码。
- 分发副本或实质性代码（含修改版）须保留完整版权和许可声明，其中包含 ZCard 名称与原仓库地址；保留 Soybean 等第三方原作者声明。
- 新增 NOTICE、中文使用说明和 README 入口，商城补齐 MIT 元数据；发行附件同时提供许可证和出处说明。

## 升级与恢复

本版无新增数据库迁移。从更早版本升级仍会执行未应用的历史迁移，请先备份数据库、配置和上传文件，再同步更新服务端、后台与商城。

货源任务已成功的商品保留；停止或结束后，可继续未完成商品、仅重试失败商品，或单独重试库存。历史限流冷却可能仍保留至原截止时间（原机制最长一小时）；升级不会直接清除无法区分真假的旧限流记录，等待到期后恢复，避免并发重复导入。

此前已完成后端全量测试、渠道回归、适配器竞态测试，并在真实出海货源对两个普通商品与一个四规格商品完成只读报价/库存验证，未触发采购。抽查通过不代表全部商品或真实支付采购已验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名更新清单。发布不代表客户站点已升级。仓库历史格式与开源路径 CI 问题不在本次业务修复范围，不能视为 CI 全绿。

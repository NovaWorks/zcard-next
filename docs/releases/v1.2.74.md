# ZCard v1.2.74

发布日期：2026-09-23

## 商品编辑与人工服务

- 商品编辑窗口通过关闭、取消、Esc 或站内返回离开时，确认放弃未保存输入；保存失败保留输入，保存期间禁止关闭。
- 明确提示规格、下单控件的独立保存/删除会立即生效；关闭商品窗口只放弃未保存输入，不撤销已经保存的操作。
- 补充下单控件取消编辑，防止隐藏的未保存输入被忽略；优化手机商品列表及编辑窗口布局。
- 补齐 Classic 商城人工服务标识图标。

## 渠道定价

- 修复固定加价保存及回显遗漏、加价无法归零、自动改价无法关闭的问题。
- 修复只更新定时等设置时汇率被重置，以及设置未保存的问题；保存失败保留表单。
- 商品导入新增默认“跟随渠道定价”，商品及规格统一按“上游价 × 汇率 × (1 + 加价比例) + 固定加价”计算，再按渠道取整。
- 已保存的独立导入策略保留；独立策略不叠加渠道加价，后续价格同步仍按渠道规则处理。
- 仅同步价格时同步已有上游 SKU 售价；修复重复同步可能覆盖人工修改商品售价的问题。

## EPUSDT / GM Pay

- 支付方式按网关实际支持的链和代币联动选择，提供可用资产刷新入口。
- 修复模板忽略所选币种、始终生成 USDT 的问题；按有效链币组合生成，并避免新增方式标识重复。
- 网关不可达、配置响应异常或未填写地址时标记未确认；不使用未确认资产覆盖已有支付方式。
- 明确支付方式优先于渠道默认配置。修改默认币种不会自动改写已有方式。
- 支持配置 Tron + TRX、Polygon + USDT/USDC 等网关已启用的组合；Polygon 为链名，POL 原生币是否可收取取决于 EP 实例实际支持与配置。

## 升级与配置

本版无新增数据库迁移。升级前备份数据库、配置及上传文件，升级后完整刷新后台。此前未保存成功的固定加价需重新设置；保存渠道设置不会立即重算已有商品，需执行价格同步。已有独立导入策略可手动切换为“跟随渠道定价”。

EP 后台须先启用对应链、代币并配置可用收款钱包，再到商城后台“支付渠道 → EPUSDT → 配置 → 刷新可用资产”添加方式。已有 USDT 方式需要明确修改其代币，不能只修改名称或渠道默认值。真实链上到账仍需商家网关联调。

Linux amd64 / arm64 发行包附 SHA256 校验和 ED25519 签名清单。发行发布不代表客户服务器已安装或重启。Docker 用户可使用 `ZCARD_VERSION=v1.2.74 bash deploy/docker-install.sh` 更新。独立第三方主题需另行适配。

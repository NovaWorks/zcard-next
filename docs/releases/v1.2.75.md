# ZCard v1.2.75

发布日期：2026-09-24

## 上游账号报价

- 修复 ACG 对接直接使用商品列表原价的问题。导入和价格同步按当前上游账号获取实际单件报价，逐个规格查询，使用账号适用的代理价格。
- 任一规格报价失败、异常或不完整时保留该商品原有价格，记录失败供重试，不回退到公开原价；报价失败的采集任务不执行删除对账。
- 统一 Dujiao 和 ZCard 的账号单件成本口径，不再将批发首档价格或上游自身成本误当采购成本；成本独立按汇率转换。
- 含价格更新的同步完整检查商品目录，避免上游只调整账号折扣、未修改商品更新时间时漏同步；补充报价超时、限速及账号切换缓存保护。

## 商品独立加价

- 保存每件导入商品选择的定价策略。自动同步、手动同步及仅同步价格继续按该规则计算，修复同步一次后额外加价失效的问题。
- 支持跟随渠道、独立比例、独立固定加价、账号报价和待定价；独立策略不会再叠加渠道加价，待定价不会被强制同步意外定价。
- 按上游规格身份跟踪同步基准，保留手工修改的商品及规格售价；明确执行强制同步时仍使用商品保存的规则。
- 商品、规格、成本和同步基准在同一事务保存，失败整体回滚；同步期间渠道凭据或定价配置变更时拒绝写入旧结果。

## 支付渠道

- 明确区分 BEpusdt 和 GM Pay，添加渠道和渠道列表分别展示品牌。
- 兼容旧 GM Pay 默认名称，保留自定义名称、现有配置、支付记录及回调标识；已有渠道无需删除重建。

## 升级说明

本版无新增数据库迁移。升级前备份数据库、配置和上传文件，升级后刷新后台。

历史商品没有保存当时的独立加价规则，不能从现有售价可靠还原。升级后会保护这类商品的现有售价；需要继续自动改价时，请重新导入对应商品并明确选择定价策略。重新导入会以本次选择替换旧规则并重算价格，请先核对策略。强制同步不会为缺失规则的历史商品猜测加价。

代理价格以当前账号的上游接口报价为准；本版按单件获取，不将数量批发档价作为所有数量的通用采购价。上游接口不支持或报价失败时可查看失败记录并重试。

Linux amd64 / arm64 发行包附 SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.75 bash deploy/docker-install.sh` 更新。发行发布不代表客户服务器已经升级；真实上游账号报价和支付到账仍需部署后联调。

版本下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.75

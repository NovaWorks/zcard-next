## 功能与源码验证

- 后端全量 `go test ./...` 通过，最终修改涉及的采购、货源、供货和签名模块回归通过；`go vet ./...` 通过。
- 本地隔离 MySQL 实际应用 55 条版本化迁移，并验证新协议账号、下单和幂等扣款；原有三种协议仍可保存。
- 契约测试覆盖真实 HTTP 路由与适配器互通、PHP 签名向量、SKU 选择、账号报价、库存、购买资料、重复提交、协议及 IP 校验，以及采购结果不确定时转人工且不自动退款或重复采购。
- 前后台类型检查、商城 1296 个翻译键检查及生产构建通过。发行提交的独立源码重新构建前后台，`fullstack` 内嵌资源一致性检查通过，产物中确认包含萌次元渠道界面。
- 当前对外供货沿用人民币、无本地 SKU 的本地卡密范围。已核实客户端契约没有独立查单、退款、订单列表和回调能力；尚未连接实际运营的萌次元站安装其 OpenApi 插件联调。

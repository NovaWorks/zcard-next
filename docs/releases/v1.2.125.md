# ZCard v1.2.125

发布日期：2026-11-23

## 采购未建单时保留原来源

修正最后复核发现的兜底分支：自动采购尚未建立有效任务时，原逻辑会重新读取商品的当前绑定；商品换绑后可能指向新的上家，商品已删除时还可能错误显示自营。

- 这类人工核对记录现在保存并显示下单时的原来源、商品及规格，不把当前绑定冒充实际采购来源。
- 商品或原渠道已经删除，仍可使用保存的原链接和编号；没有历史来源时明确显示来源待核实，不生成猜测链接。
- 兼容识别此前由同一兜底逻辑生成的记录，优先读取原订单快照；不改变采购、扣款、退款或交付状态，不重复创建采购任务。
- 保留 v1.2.124 的商品/采购入口、复制编号、每件订单商品分别定位及渠道链接模板功能。

## 升级说明

此修复没有额外数据库迁移。直接升级到本版即可；从v1.2.123及更早版本升级时，仍会应用上一版新增的两列可空来源快照迁移。升级前备份数据库、配置及上传文件，保留原加密密钥，配套更新完整程序后重启。

提供 Linux amd64 / arm64 完整程序、SHA256 校验、ED25519 签名清单及双架构 Docker 应用和配套更新器。

新增回归先复现了换绑、商品删除、无历史记录及旧兜底记录的错误来源，再验证修复。发布不代表客户站点已部署，也没有自动再次采购或处理历史资金。

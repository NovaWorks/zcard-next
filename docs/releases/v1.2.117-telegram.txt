📦 ZCard 众卡 v1.2.117 更新日志
📅 发布日期：2026-11-19

🔄 自动上下架完善
• 不再只判断库存：上游停售、删除，或在完整对接目录中已找不到的商品，会自动下架本地已开启自动管理的商品。
• 完整空目录也会对账；接口失败、分页未拉全或任务取消不会据此批量下架，商品与订单历史保留。
• 锁定、本地发货和人工操作继续受保护。停售或删除后需核实再人工恢复，普通缺货补货沿用原自动恢复规则。

🔌 独角数卡 dujiao-next 对接修复
• 按所选规格读取真实库存，修复有货被读成 0、全部规格停用显示不限库存，以及首个规格缺货影响其他规格的问题。
• 补齐人工交付表单：同步字段和校验规则，付款前校验，订单保存快照，采购时正确转发账号等填写资料。
• 已退款、部分退款、退款中和取消状态不会再被旧交付记录覆盖；转人工核对，避免错误发货。

🖥 商品管理更适合笔记本
• 分类栏可收起，更多筛选可折叠，表格和操作列更紧凑，增加商品展示空间。
• 编辑、复制保留快捷入口，发货设置、锁定、评价、删除等放进“更多”，权限规则保持有效。
• 后台与云帆商城切换分类自动清除旧搜索词，避免误以为分类没有商品。

☁️ 云帆主题 0.1.40
• 电脑端快捷支付直接列出支付方式及手续费；手机继续使用底部购买区和弹层选择。
• 手机搜索、分类、排序重新分层排版，网格 / 列表 / 大图改为清晰的文字切换，当前视图高亮。
• 新主题包与主题源码随本版 Release 提供，需要在主题管理单独上传启用。

📋 近期功能回顾
本版也包含前两版已发布的商品复制、规格和下单控件复制、规格保存提示完善，以及实体发货运费到付。

📌 升级提醒
本版无新增数据库迁移。请先备份、保留原加密密钥，更新完整程序或 Docker 镜像并重启；使用云帆的站点另外安装 yunfan-0.1.40.zip。
已有需要填写资料的上游商品，请重新采集或导入以同步表单；与本地手工控件冲突会提示整理，不会直接覆盖。
支持 Linux amd64 / arm64 正式发行包与 Docker 更新。版本发布不代表站点已经升级，真实支付及交付仍需在升级后验收。

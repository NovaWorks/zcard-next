# ZCard v1.2.130

发布日期：2026-11-25

修复 ACG 货源同步中，部分商品配置格式不兼容、单件报价异常中断整批同步及请求间隔未覆盖逐规格报价的问题。

- 支持 INI 文本、空数组、空对象和标准规格配置对象；损坏或不完整的配置继续报错，保留原商品和规格。
- 单件商品报价失败后保留原价格及 SKU，继续同步其余商品，并汇总成功、失败和跳过数量。部分成功显示“部分完成”；报价异常时不执行未见商品下架对账。
- 已确认停售或不支持自动采购的商品跳过对应报价、库存补查；读取遇到限流或认证失败后停止后续请求。
- 定时计划新增“报价请求间隔(ms)”，默认 500ms，覆盖规格读取、逐 SKU 报价和请求重试。分页间隔仍以秒计，库存批次间隔单独设置。
- 货源任务预算调整为 6 小时，目录读取期间持续更新心跳并检查取消；重试清理旧错误及本次统计，可恢复导入保留已保存进度。
- 库存部分失败支持仅重试失败库存。合法的 race 规格编码（如“美国|”）保持不变。

本版没有新增数据库迁移。升级完整程序并重启后刷新后台，可重跑未完成同步；已保存商品的库存问题可单独重试库存。已有商品、货源及规格映射无需删除或重建。升级前备份数据库、配置及上传文件，保留原加密密钥。

提供 Linux amd64 / arm64 完整程序、签名更新清单、SHA256 校验及双架构 Docker 镜像。独立付费主题不包含在主程序发行包中。

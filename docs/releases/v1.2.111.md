# ZCard v1.2.111

发布日期：2026-10-25

## 商品详情销量修复

- 修复商品列表有销量、详情页却始终显示 0 的问题。详情接口接入与列表相同的订单销量汇总，按同一口径返回真实销量。
- 修复只影响详情接口返回的数据，无需重新导入商品、补写销量或修改历史订单。

## 自定义图形验证码

- 后台「设置 → 安全」新增验证码位数和字符类型：支持 4–8 位，提供纯数字、纯字母、数字字母混合三种格式，默认保持 4 位纯数字。
- 字母不区分大小写；混合格式保证每张验证码同时包含数字和字母。保存设置后，新生成的验证码立即使用新格式，无需再次重启；已生成且未过期的验证码仍按原答案校验。
- 内置商城的登录、注册、找回密码、游客下单，以及后台登录输入框随当前图片调整长度、字符限制和输入提示，支持电脑与手机使用。
- 修复验证码内存存储的并发计数竞态，保留 5 分钟有效期和一次性消费，错误答案提交后也不能重复使用原图。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置和上传文件，保留原加密密钥，更新完整发行包并重启服务端，同时刷新后台与商城页面。从更旧版本升级仍需执行已有累积迁移。验证码保存在进程内存中，服务重启后请刷新验证码图片。

独立安装的第三方主题不随主程序发行包更新。主题如仍将验证码写死为 4 位数字，需更新主题以适配验证码接口的长度和字符类型，再启用新的验证码格式；完成适配前可继续使用默认的 4 位数字。

本地验证已通过销量与相关订单回归、验证码格式和设置校验、并发竞态检测、前后台类型检查及生产构建、桌面与 390px 手机浏览器的输入和提交回归，以及 fullstack 嵌入资源检查与构建。验证覆盖默认兼容、全部合法位数与字符类型、配置变更后旧验证码继续有效、过期清理和并发一次性消费。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级，实际站点的主题兼容和页面显示需在升级后验收。

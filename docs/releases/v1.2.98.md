# ZCard v1.2.98

发布日期：2026-09-30

## SMTP 配置与邮件发送修复

- 修复后台已保存 SMTP 配置，注册或找回密码仍提示 `identity.EMAIL_NOT_READY` 的问题。邮件通道读取后台保存的独立配置字段，兼容旧版 SMTP 配置，后续配置保存后无需重启生效。
- 修复发件人名称被误传入 SMTP 信封地址的问题，中文名称与主题正常编码；新增独立发件邮箱，可与 SMTP 登录账号分别设置。
- 后台「设置 → 邮件短信」支持选择普通 SMTP、SSL/TLS、STARTTLS 或自动模式，连接方式与端口可分别配置，支持服务商提供的自定义端口。
- 支持自动选择、PLAIN、LOGIN、CRAM-MD5 和无需认证中继。明确选择 STARTTLS 后，服务器不支持或升级失败会报错；自动模式保留原有端口识别行为。
- 新增 SMTP 服务器证书校验开关，默认开启。后台说明自签名证书、证书链、域名不匹配等情况，以及普通连接与关闭校验的影响；自建服务由管理员按实际环境配置。

## 测试邮件与错误诊断

- 新增「测试邮件发送」入口，填写收件邮箱、邮件标题与内容，使用已保存的 SMTP 配置立即测试，发送期间阻止重复提交。
- 失败结果显示具体阶段、服务器地址与端口、连接和认证方式、SMTP 状态码、服务器原始错误及排查建议，帮助区分 DNS、网络、防火墙、TLS 证书、登录认证、发件权限和收件地址等问题。
- 未配置邮件通道不会误报成功；发送支持超时与取消，测试结果记录到发送日志，SMTP 密码在诊断和配置审计中脱敏。
- 后台补充 SPF / DKIM / DMARC 与邮件投递说明。DKIM 的 Selector 和 TXT 公钥记录配置在发件域名 DNS，签名私钥由邮件服务器管理；测试提交成功表示 SMTP 服务器已接受，最终到达收件箱仍需查看投递日志与收件结果。

## 升级说明

本版无新增数据库迁移。请先备份数据库、配置和上传文件，使用完整发行包同步更新服务端与内置后台、商城，并刷新浏览器。

已有 SMTP 配置默认沿用自动模式，证书校验默认开启；升级后核对连接方式、端口、账号和发件邮箱，保存配置后发送测试邮件。配置读取修复不会自动补发历史验证码或订单邮件，SMTP 服务器的证书、DNS 记录和账号授权仍需自行配置。

验证覆盖 Go 全量测试、实际 TCP SMTP 测试服务上的普通连接 / SSL/TLS / STARTTLS 与认证组合、证书及服务器拒绝错误的 HTTP 诊断，以及后台类型检查、生产构建、电脑和手机配置保存与错误提示。测试使用隔离邮件服务及页面接口，不代表真实邮箱收件已经验收。

发行包内置后台与默认商城，提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.98

# ZCard v1.2.101

发布日期：2026-10-01

## 分类多选删除

- 后台商品分类直接显示多选框，支持全选当前筛选结果、跨搜索保留勾选和清空选择；分类页面与商品管理中的分类弹窗保持一致。
- 删除前确认，仅处理勾选分类，按先子后父顺序逐个删除。有商品或未选中子分类的分类保留，不级联删除商品或未选中的分类。
- 删除期间显示进度并阻止重复操作；失败项保留勾选并展示原因，可只重试剩余项。删除响应丢失时以刷新后的分类列表确认结果，已成功项不会重复提交。
- 分类删除按删除权限控制；仅有删除权限的管理员可使用多选，只有读取权限时不显示勾选或删除操作。认证或权限失败时停止后续请求。

## 接码游客浏览与公开名称

- 游客可直接筛选国家、服务及分页报价、查看零售价并选择号码选项；点击「登录后购买」进入登录页，保留返回当前商品的地址。
- 冻结购买报价、下单、余额、号码记录及会话操作继续要求会员登录。游客浏览不会请求会员钱包与号码记录，不保存购买报价或分配号码；隐藏、停售和隐藏分类的访问限制继续生效。
- 商品列表、详情、供货商品数据及会员订单的公开显示使用通用接码服务名称，处理旧自动生成的「渠道名 · 接码服务」标题和说明标题；自定义公开名称和服务说明保留，不修改后台供货连接名称或历史结算数据。
- 调整接码页面操作提示，使用公开服务说明，适配电脑和手机，保留登录会员原订单与原操作的响应丢失恢复流程。

## 升级说明

本版无新增数据库迁移。请备份数据库、配置及上传文件，保留原加密密钥，使用完整发行包同步更新服务端与内置后台、商城，并刷新浏览器。从 v1.2.99 之前升级仍需执行累积迁移；独立第三方主题需自行适配游客浏览和公开商品名称处理。

接码购买仍限定主站登录会员、CNY 余额和单件独立订单，新购继续默认开启；`ZCARD_SMS_SALES_ENABLED=false` 可暂停新购，历史查单、操作和退款继续运行。供货端仍需支持渠道目录、动态选项、报价及采购接口。

发布验证已通过 Go 全量测试、受影响模块 `go vet`、分类保护及接码游客鉴权的 race 回归、前后台类型检查与生产构建、fullstack 内嵌资源检查，以及 390px / 1440px 页面测试。页面回归覆盖筛选多选、取消确认、先子后父删除、失败与响应丢失恢复、读取/删除权限、游客浏览和登录跳转，并保留会员原订单重试、收码及退款验证。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。页面和接口回归不代表真实供应商付费取号、实际收码或资金闭环已验收；版本发布不代表客户站点已自动升级。

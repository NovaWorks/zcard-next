# ZCard v1.2.106

发布日期：2026-10-02

## 上游商品目录导入修复

- 修复 MySQL 环境下导入异次元等上游商品目录时出现 `Error 1038 (HY001): Out of sort memory`、目录无法展示的问题。
- 最新目录快照先查询记录 ID，再按主键读取完整目录，避免大体积 JSON 参与排序，减少对 MySQL 排序缓冲的依赖。
- 保留站点隔离、货源身份校验、快照有效期、缓存复用、强制刷新和并发刷新锁，已有商品与货源映射无需重新建立。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置及上传文件，保留原加密密钥，更新完整发行包并重启服务端。升级后重新打开“导入商品”；仍显示旧错误时点击“重新加载”，无需删除货源、已导入商品或原有映射。从旧版本升级仍需执行已有累积迁移。

本次修复不需要全局增大 MySQL `sort_buffer_size`。上游目录能正常加载后，个别魔改协议、商品类型及自动采购仍需按对应上游单独验证。

Go 全量测试、go vet 与 fullstack 内嵌资源检查通过；真实 MySQL 8.4 在 256 KiB 排序缓冲下，使用 2,250,349 字节目录复现旧查询的 1038 错误，新查询成功读取完整内容。回归同时覆盖站点及货源身份隔离、有效期、强制刷新和未完成目录加载任务的快照复用，并接入 CI。

提供的上游账号认证和目录读取已验证成功，未发起真实付费采购；上述验证不代表所有魔改上游、全部商品自动采购或客户生产站点已验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

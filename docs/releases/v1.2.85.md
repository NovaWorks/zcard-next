# ZCard v1.2.85

发布日期：2026-09-27（北京时间）

## 推荐注册赠送会员等级

- 后台可为邀请人设置“邀请注册赠送等级”；新客户通过其推荐码或推广链接注册后，立即获得该等级，使用后台为该等级配置的折扣。
- 注册时保存获赠等级，邀请人以后调整赠送设置只影响新注册客户，不改变已经注册客户的等级，也不覆盖后台人工改级。
- 兼容现有推荐码与历史邀请链接；未配置赠送等级时沿用原有注册规则，新客户不会自动获得赠送等级的权限。
- 注册页展示可公开的邀请权益，推广中心展示自己的赠送设置，会员中心展示等级来源；隐藏等级和联系购买等级继续遵守展示限制。

## 客户信息支持修改等级

- 后台客户详情新增“修改等级”和“设置赠送等级”，分别管理客户自己的等级与其邀请新客户时赠送的等级。
- 人工指定等级优先生效，可升级或降级；取消人工指定后，系统按已获赠等级与积分等级中折扣更优惠的一项计算，不叠加折扣。
- 支持明确清除注册获赠等级并恢复自动计算；保留原有积分累计与升级规则，不修改历史订单金额。
- 新增邀请赠送等级配置权限和操作审计；被客户或赠送设置引用的等级不能直接停用或删除。
- 注册绑定、等级保存与审计在同一事务完成，补齐并发改级、邀请设置变化与数据库无变化更新的处理。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 数据库迁移。请先备份数据库、配置和上传文件，使用完整发行包同步更新服务端、后台与商城，检查迁移日志并刷新浏览器。已有客户不会因为本次升级自动补领赠送等级；需要调整时由后台修改。

管理员可在客户详情配置邀请赠送等级；自定义员工角色需按需授予“配置推荐注册赠送等级”权限。独立第三方主题需要适配新的邀请权益与等级来源展示。

验证覆盖 Go 全量测试、三种数据库迁移、真实 MySQL / PostgreSQL 并发回归、前后台类型检查和生产构建，以及电脑和手机界面回归。界面测试使用模拟接口，不代表客户站点真实注册与支付流程已经验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名更新清单。发布不代表客户站点已经升级。

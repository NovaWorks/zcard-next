# ZCard v1.2.116

发布日期：2026-11-06

## 商品复制

- 后台复制商品时，新商品会一起保存 SKU 组合、规格名称、独立售价和成本。有对应权限的账号也会复制下单控件及其校验规则。
- 副本默认下架。库存、货源绑定和直发内容需要单独配置。商品与复制的配置一起保存，失败时整笔回滚。
- 之前仅复制了基础资料的商品，需从原商品重新复制，才能自动带入规格。

## 规格保存提示

- 修复给实体商品添加首个规格时，商品级库存或已有无规格订单被误报为“规格名可能重复”的问题。后台会说明具体原因，并在商品级库存大于 0 时提示先处理库存。
- 同一商品下确实存在同名规格时，会明确提示修改规格名。不同名称可以分别保存。

## 升级说明

本版无需新增数据库迁移。请使用完整发行包配套更新服务端和管理后台。

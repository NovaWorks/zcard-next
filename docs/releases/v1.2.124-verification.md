## 功能与升级验证

- 商品和采购列表明确显示上游入口；采购详情可复制商品/规格编号，显示原请求号、追踪号和上游单号。销售订单按每个商品独立展示来源。
- 下单来源及卡密采购来源分别保存。用例覆盖修改商品绑定、改名、修改网站、删除渠道、删除采购记录后回落原下单快照；历史采购只使用原采购连接和原商品编码。缺少证据时不套用当前商品绑定。
- 萌次元 `12~52` 拆为商品 12 / 规格 52，商品路由 `/item?id=12`；ZCard 使用 `/product/编号`。未知路由保留网站与编号，可配置模板；打开商品后仍须核对原规格。
- 链接路径及查询参数编码、组合编号、超出 JavaScript 精度的连接 ID、凭据清理、无效协议及主机占位拒绝通过测试。后台来源没有进入买家订单 DTO；只读入口不会触发采购。
- SQLite、MySQL、PostgreSQL 各新增一项由 Atlas 生成的迁移，仅增加两列可空 JSON 来源快照。历史数据、金额及库存设置保留；本地实际三方言升级及远端 MySQL/PG 集成通过。
- Go 1.26.4 后端全量测试和 vet 通过；来源解析、历史恢复、采购详情的定向竞态检查通过。后台类型检查、默认商城类型检查、1297 个翻译键检查和生产构建通过。
- 1440px / 390px 浏览器覆盖列表入口、采购详情、商品/规格复制、多商品分别定位，以及原采购交付恢复和人工补发。来源测试断言无写入请求。内嵌资源清单校验通过。

# ZCard v1.2.109

发布日期：2026-10-03

## 短信接码报价修复

- 修复对接 zcard-market 短信渠道时，列表和库存正常显示，但点击“确认价格”出现 `upstream 400 (CODEC)`、`country_id` 无法解析为整数的问题。
- 报价请求将国家与服务平台标识校验后按整数发送，同时修复 `platform_id` 的同类错误；空筛选保留原有默认语义。
- 非法、负数或超出整数范围的标识在发送前被拦截。保留原有报价签名、会员权限、零售加价及购买、收码和退款流程。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置和上传文件，保留原加密密钥，更新完整发行包并重启服务端。从旧版本升级仍需执行已有累积迁移。

无需重新导入渠道商品、删除货源、重建商品映射或修改正常供货凭据。升级后重新选择国家与服务平台，再点击“确认价格”。仅更新供货端不能修复旧客户端发送字符串字段的问题，发起报价的开源站点需升级。

回归测试覆盖真实供货 HTTP 接口解析、国家与平台的整数类型、空值、零值、大整数精度以及非法标识提前拒绝，已通过相关后端测试、架构检查和静态检查。真实供应商付费取号、实际收码及客户站点升级需分别验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.109

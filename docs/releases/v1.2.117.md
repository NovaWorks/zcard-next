# ZCard v1.2.117

发布日期：2026-11-19

## 自动上下架与上游商品删除

- 开启自动上下架的对接商品会定期检查完整上游目录。上游明确停售，或完整目录中已找不到该商品时，自动下架本地商品，不删除商品及订单历史。
- 完整目录为空也会执行缺失对账。接口失败、任务取消、分页不完整、重复商品或分页总数变化时，跳过缺失下架，避免误判。
- 自动管理继续保护锁定商品、本地发货、重复发货及检查期间发生的人工操作。上游停售或删除后的商品需核实后人工恢复；普通缺货补货沿用原恢复规则。

## dujiao-next 货源兼容

- 修复实时库存读取了不存在的商品级字段、忽略指定 SKU 的问题。按买家所选规格读取库存；商品参考库存汇总启用规格，未知库存不会变成 0 或不限库存。
- 修复全部规格停用被显示为不限库存、首个规格缺货掩盖其他有货规格的问题。完整规格目录确认本地在售规格已被移除或停用时，纳入自动下架判断。
- 同步人工交付表单的字段标识、名称、必填、选项、长度、格式和数字范围等规则。付款前校验填写内容，按订单项保存快照，采购时使用原字段标识转发至上游。
- 已有商品需重新执行商品采集或交互导入以同步表单。上游字段与本地手工控件冲突时明确报错，不覆盖手工控件；不支持或无效的规则不会被静默忽略。
- 保留退款中、已退款、部分退款和已取消等订单状态。旧交付记录不会覆盖这些状态或触发新发货；转人工核对上游金额及后续处理，不自动推断本地退款金额。
- 上游明确拒绝填写资料时转人工处理，避免反复提交，并避免将上游可能回显的客户资料写入错误日志。

## 商品管理空间与搜索

- 分类栏支持展开与收起；筛选条件分组，低频筛选收进“更多筛选”，折叠后仍显示已启用条件数量。
- 表格缩小行内占用，名称限制行数，售价、成本和加价比例紧凑显示；保留编辑、复制入口，其余操作收进“更多”，继续遵守权限与商品锁定规则。
- 选中商品后才显示批量操作栏，增加笔记本上的商品展示空间。后台切换分类会清空旧关键词并重置分页。

## 云帆 Yunfan 0.1.40

- 商城切换分类、全部商品或推荐商品时清空旧关键词，避免分类被上次搜索条件过滤。
- 电脑端商品快捷支付直接逐项显示可用支付方式、手续费和选中状态。手机底部购买区保留弹层选择，避免支付列表遮挡商品资料。
- 手机商品浏览区按搜索、分类与排序、商品标题与视图切换分层排列。视图切换使用“网格 / 列表 / 大图”等宽文字按钮，并突出当前选择。
- 主题包和可复现构建的主题源码作为本次 GitHub Release 的独立附件提供。主程序升级不会自动替换已安装的独立主题。

## 近期功能一并保留

本版继续包含 v1.2.115—v1.2.116 的商品复制、SKU 与下单控件复制、规格保存错误说明，以及实体商品运费到付功能；这些为之前已发布功能，本次没有改变副本默认下架和库存、货源需单独配置的规则。

## 升级说明

- 本版无新增数据库迁移。先备份，保留原加密密钥，更新完整发行包并重启，使服务端、后台和内置商城保持配套。
- Docker 提供 Linux amd64 / arm64 应用和更新器镜像及签名发行描述符。
- 使用云帆的站点需在主题管理单独上传并启用 `yunfan-0.1.40.zip`，再刷新商城页面；本次主题包已包含 0.1.38—0.1.40 的上述更新。
- 检查货源处于启用状态，目标商品已开启自动上下架；升级后等待下一轮检查，或手动执行状态检查。已有人工交付商品请重新同步商品及表单后再销售。
- GitHub、Docker 版本发布与隔离验证不代表客户生产站点已完成升级或真实交易验收。频道公告由用户手动发送。

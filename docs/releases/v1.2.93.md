# ZCard v1.2.93

发布日期：2026-09-30（北京时间）

## 订单查询与取货密码修复

- 修复查询密码输错一次即被锁定的问题；同一 IP 与同一订单连续失败 5 次才锁定 30 分钟。
- 前 4 次失败明确提示剩余尝试次数，第 5 次及锁定期间提示等待时间，不再统一误报密码错误；锁定期间查询不会延长锁定时间。
- 验证成功清除未达到锁定阈值的连续失败计数；计数持久化并处理并发更新，订单详情与取货接口共用限制。
- 无已保存查询密码的支付回跳只提示输入密码，不消耗失败次数；默认商城查询失败后停止自动轮询，避免自动请求耗尽次数。
- 默认商城取货页补充失败次数和锁定说明；订单查询内部故障显示稍后重试，不再误导为密码错误。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 的取货失败计数增量迁移。升级前备份数据库、配置及上传文件，使用完整发行包同步更新服务端与内置商城，检查迁移日志并刷新浏览器。已有锁定保留原过期时间，升级不会立即解除之前的锁定。

限制沿用 IP 与订单组合；不会更改订单付款、发货状态或查询密码。独立安装的 Yunfan 等第三方主题需另行更新，特别是收银台错误提示和自动轮询行为；主题不包含在主程序发行包中。

本次修复不包含邮件投递修复，也不会自动补发历史订单或邮件。客户线上订单仍需在实际升级后核对。

已验证后端全量测试、SQLite 历史锁定迁移、真实 MySQL / PostgreSQL 迁移与并发计数、前端构建，以及本地页面的剩余次数和锁定提示。浏览器提示验证使用模拟响应，客户真实订单仍需升级后验收。

发行包内置后台与默认商城，提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.93 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已自动升级。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.93

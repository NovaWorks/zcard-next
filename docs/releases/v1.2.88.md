# ZCard v1.2.88

发布日期：2026-09-27（北京时间）

## 渠道自动发货修复

- 修复普通渠道采购使用本地自增编号作为请求号，可能与其他店铺在 ACG 上游撞号、导致支付成功后转人工而未自动发货的问题。
- 新采购使用持久化的 19 位随机请求号，兼容 ACG 请求号字段长度；同一订单项增加数据库唯一约束，避免并发支付事件重复采购。
- ACG 下单遇到网络中断、网关异常、限流或非 JSON 响应时，不再自动重复提交采购，避免首次结果不明时再次请求并掩盖原始错误。只读查单继续保留重试。

## 采购回执与发货恢复

- 同步返回卡密时也先保存上游订单号，再加密保存卡密和完成本地交付；本地回执保存失败后，可以查询原上游订单恢复发货。
- 采购结果返回后使用独立、限时的保存流程，避免请求超时或取消导致已成功的采购结果无法落库。
- 调整重复请求提示，明确需要核对原上游订单，不能仅凭重复错误断定本单已经成交。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 的采购订单唯一索引迁移，保留原采购请求号、上游单号、状态和已有卡密回执。升级前请备份数据库、配置和上传文件，使用完整发行包并检查迁移及启动日志。

新编号仅用于新建采购，旧异常单不会自动更换编号或重新采购。已人工补发或已完成订单无需重复处理；历史订单缺少上游单号或回执时，仍需管理员核对实际扣款与出货情况。网络响应完全丢失时不能保证自动恢复，不会用新编号试购。

验证覆盖跨店铺相同本地编号、重复支付事件、回执保存失败、请求取消、ACG 异常响应、查询重试，以及三种数据库的历史数据保留与并发采购限制；相关模块回归和竞态检测通过。测试使用本地数据库与模拟上游，未发起客户渠道的真实付费采购。

发行包提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.88 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已经安装或重启。

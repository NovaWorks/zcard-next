# ZCard v1.2.127

发布日期：2026-11-23

## 实际数量报价、购买资料与预选卡

- 同步上游的最少、最多购买数量；上游明确无上限时不再截为 99，仍受库存、请求和金额范围约束。
- 按实际数量、规格、购买资料与选卡核算整单总价，确认金额后建单。修改购买条件或报价过期时重新核算，不以目录单价乘数量代替实时总价。
- 支持文本、密码、多行及选项资料，保留必填、正则、显示名称和实际值；有意义的空格和换行不擅自删除。
- 支持上游开放的可选卡片预览；不选时随机交付，选定单张时数量固定为一，不能绕过起购限制。选卡不占用上游库存，采购前再次确认。
- 完善购物车购买资料、实际报价、积分金额确认、失效报价恢复及不明确结果的原请求核对。
- 采购前确定拒绝按原失败策略处理；上游接受后的超时与不明确回执保持核对，避免重复采购或错误退款。自动退余额仍限单商品、会员、人民币、无手续费余额订单，其他情形保留人工核对。

## 升级说明

SQLite、MySQL、PostgreSQL 均有新增版本化迁移：为购买控件选项名称、订单项加密采购资料增加可空列。升级前备份数据库、配置及上传文件，保留原加密密钥，完整更新服务端及配套店铺资源后重启。

先升级 Market v1.2.108 并同步上游商品，再升级开源版 v1.2.127 并重新同步 ZCard 货源。依赖新规则的商品需要供货端支持 card_purchase.v2；此前已经下架的商品核对后手动上架。

提供 Linux amd64 / arm64 完整程序、签名更新清单、SHA256 校验及双架构 Docker 应用和更新器。

本地双站测试使用独立程序、数据库和钱包，只有上游被模拟，不代表真实上游付费验收或客户生产站点已经部署。GrizzlySMS 和原有未完成的短信诊断不在本次发行中。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.127

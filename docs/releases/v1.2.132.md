# ZCard v1.2.132

发布日期：2026-11-26

修复社交服务订单缺少下单资料，以及自定义评论校验不一致导致付款后转人工核对的问题。

- 我的订单列表显示下单时的目标链接，订单详情显示原始链接、服务数量和评论等填写内容；已完成订单也能继续查看，商品或货源设置变化不会覆盖原资料。
- 社交服务的“查看交付”和取货查询进入服务订单详情，查看处理进度及原始配置；手机长链接完整换行，完成状态统一显示为“已完成”。
- 不允许空行的评论服务在确认价格前提示空行和末尾换行。服务端同步拦截，不生成可付款报价；合法的重复评论和换行保持原样。
- 对已付款但能明确确认未发送请求的本地校验失败，按原订单完成退款，避免误记为提交结果未知。真正的超时、断线或结果未知继续保留原单核对，不会自动重复下单。

本版无新增数据库迁移。更新完整程序并重启后刷新商城和后台。已保存的历史订单资料可直接查看；此前已进入“提交结果未知”的订单仍需核对后处理，升级不会自动补发或推断退款。

提供 Linux amd64 / arm64 完整程序、签名更新清单、SHA256 校验及双架构 Docker 应用和更新器。

# ZCard v1.2.87

发布日期：2026-09-27（北京时间）

## 下游供货订单安全修复

- 标准供货 API 的订单列表、详情、取消和退款限定当前认证下游账号；其他账号的订单统一返回不存在，管理员后台的全量订单查看能力保持不变。
- 订单幂等范围调整为“下游账号 + 下游订单号”，不同账号使用相同订单号各自独立建单、扣款和交付；同账号重复请求保持幂等，修改商品或数量时拒绝复用订单号。
- 同步覆盖 Dujiao / ACG 兼容接口，完善购买数量、金额溢出及回调归属校验。

## 扣款、交付与退款一致性

- 扣款、锁卡、卡密快照、订单状态和回调登记在同一事务完成，失败完整回滚；回调在提交成功后入队。
- 余额写入按账号串行，避免并发充值、下单及退款覆盖余额。
- 取消与退款共用事务和退款幂等键，按订单实际扣款减去历史退款计算，避免未付款加余额和重复退款；兼容旧版取消、退款流水。
- 已交付或交付中的订单需人工处理；旧订单即使状态滞后，只要已有卡密交付快照，也禁止自动退款。
- 修复兼容接口退款后的状态与实退金额展示。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 的供货订单唯一索引迁移，保留原有订单数据。建议所有开启对外供货的站点尽快升级。升级前备份数据库、配置和上传文件，使用完整发行包并检查迁移及启动日志。

已验证三个协议的跨账号访问限制、重复请求与退款、失败回滚、SQLite 旧订单升级，以及真实 MySQL / PostgreSQL 并发行为；相关供货、支付、库存、数据库测试、架构检查、静态检查和后端构建通过。

本版阻止后续越权和重复退款，不会自动修改历史异常余额或流水。历史上是否已发生异常访问或重复退款，需要站点管理员核对访问日志、订单和账本；已交付卡密不能撤回。

发行包提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.87 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已经安装或重启。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.87

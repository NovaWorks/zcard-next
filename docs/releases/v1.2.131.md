# ZCard v1.2.131

发布日期：2026-11-25

修复 ACG-Faka 二级货源站列表已有库存，状态同步仍逐件补查并触发网关限流的问题。

- 常规同步默认采用列表中有效的非负总库存（包含 0），不受 `shared_sync=1` 影响。跳过多余的单品库存、空规格目录预读及逐 SKU 库存补查，保留原有商品规格和价格。
- 渠道编辑新增“ACG 库存来源”：默认“优先列表库存”，列表数据不可靠时可切换为“逐件实时补查”。库存缺失、无效或为 -1 时仍补查确认。
- 列表总库存不复制为每个 SKU 的库存。购买前继续实时检查所选商品/规格，报价和正式导入继续确认实际规格与账号价格。
- 兼容停售、下架或不存在提示后附带标点和说明文字；人工发货、旧版预选及已停售商品在价格同步中跳过，正常商品继续完成。鉴权、限流和其他真实错误仍保留失败提示。
- 保留 `config: []`、`config: {}` 和标准规格对象兼容，并补充客户示例的直接接口测试。

本版无新增数据库迁移。更新完整程序并重启后刷新后台，默认使用列表库存；已有商品、渠道及规格映射无需删除或重建。之前已进入限流冷却的渠道需等待原冷却结束后再同步，升级不会自动清除真实限流状态。手动补查及独立低库存加速检查仍使用各自的实时读取规则。

提供 Linux amd64 / arm64 完整程序、签名更新清单、SHA256 校验及双架构 Docker 应用和更新器。独立付费主题不包含在主程序发行中。

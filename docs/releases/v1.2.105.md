# ZCard v1.2.105

发布日期：2026-10-02

## 默认结算货币

- 基础货币统一作为站点默认结算货币。尚未配置商品价格或开始资金业务的站点，添加并启用 AUD 后，可通过下拉或货币列表的“设为默认结算”切换；切换时同事务重新归一全部汇率，基础货币汇率固定为 1。
- 前端显示货币独立于结算货币。订单、钱包账户和流水记录真实基础币种；支付明细区分基础币金额、显示币参考金额和网关实际扣款，充值及提现按基础货币输入。
- 支付渠道按币种能力筛选，Stripe、PayPal 接收明确的扣款币种与金额快照；仅支持 CNY 的支付驱动、独角数卡／ACG 兼容供货协议及接码销售不接受 AUD 基础金额。跨币回调使用建单时的快照，汇率变化不会重新解释已创建的付款。
- 已有商品、订单、资金记录或金额配置时拒绝直接切币，覆盖会员金额门槛、消费积分计价、固定手续费、优惠与供货定价，防止历史金额被改标。切币与首次定价、账户创建共用数据库锁。
- 补齐旧 CNY 订单退款和旧充值回调的币种检查；遇到基础币配置与旧钱包币种不一致时明确要求迁移，不将 CNY 余额显示或记账为 AUD。
- 后台商品、规格、运费、退款、调账、会员门槛、固定手续费和赠送档位等金额输入及图表单位随基础币更新。

## 简体中文与英语

- 默认语言改为单选下拉，启用语言改为多选，当前支持简体中文与英语；默认语言必须属于启用列表，至少保留一种语言，批量保存统一校验最终状态。
- 默认商城主题覆盖内置页面、按钮、错误、空状态、无图占位、日期及无障碍文案。首次访问使用站点默认语言，客户已保存且仍启用的选择优先；仅启用一种语言时隐藏切换器，停用语言后清除旧选择。
- 切换语言保留表单输入、商品数量和购物车；公告、横幅、文章及详情刷新当前语言内容，请求发送对应语言，HTML 语言及 SEO 同步更新。
- 文章编辑支持分别填写简体中文与英语，并保留其它已存在语言内容；未填写翻译时回退原文，不自动翻译商品名称、店名及商家自定义内容。兼容已有中文、英语地域别名，清空英语时不会恢复旧别名内容。
- 内容查询明确隔离站点，横幅缓存同时区分站点、位置与有效语言，避免语言切换或分站请求混用内容。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置及上传文件，保留原加密密钥，使用完整发行包同步更新服务端、后台和默认商城主题，并刷新浏览器。从旧版本升级仍需执行已有累积迁移；独立第三方主题需另行适配。

已有价格或资金的站点不能通过修改下拉直接将 CNY 改为 AUD。本版不提供历史金额迁移工具；需要先制定包含价格、余额、订单及汇率的迁移方案。若旧版本已经保存了非 CNY 基础币设置，但钱包或订单实际仍为 CNY，升级后相关操作会拒绝币种错配，请先核对账务及配置。

验证覆盖 Go 全量测试、go vet、AUD 订单与钱包支付、重复回调、充值及退款、旧 CNY 钱包读取与退款回滚、语言策略与内容缓存回归、前后台类型检查和生产构建、fullstack 内嵌资源检查。桌面与手机浏览器验证下拉联动、保存回显、失败重试、切换保留表单和购物车，以及 AUD 结算与 USD 网关扣款的费用展示。

浏览器和支付链路验证使用隔离测试库及本地模拟接口，不代表真实支付网关、上游或客户生产站点已验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

# ZCard v1.2.77

发布日期：2026-09-24

## BEpusdt 多链、多币种收款

- 新增“多链收银台”模式：一个 BEpusdt 渠道即可让用户在 BEpusdt 收银台选择实际可用的币种和网络，使用原生 create-order 接口。BEpusdt 与 GM Pay 继续使用独立驱动和配置。
- 支持限定 USDT、USDC、TRX、ETH、BNB、TON（BEpusdt 协议标识为 GRAM）；不选币种表示允许网关全部可用币种。实际可选网络由 BEpusdt 钱包、汇率和启用状态决定。
- 固定模式补齐 BEpusdt v1.24.2 的全部 23 个交易组合，覆盖 Tron、Ethereum、Polygon、BSC、Aptos、Solana、X-Layer、Arbitrum-One、Base、Plasma、Ton。
- 后台按模式显示固定网络或收银台币种，支持多选、清空限制、保存及回显；旧配置默认保留固定模式和原网络。
- 收银台订单不再要求返回固定 trade_type。重试沿用同一支付单及商户单号，保留商城支付期限；未完成或待核对支付期间阻止修改网关凭据、模式、币种和网络。
- 商品付款、会员充值、供货余额充值继续按签名、渠道、商户单号、网关单号及 CNY 应收金额核对；加密货币实际收款数量不作为商城入账金额，重复通知不会重复入账。

## 升级与配置

本版无新增数据库迁移。升级并刷新后台后，进入“支付渠道 → BEpusdt → 配置”，将“收款模式”改为“多链收银台”，按需选择“收银台币种”。先在 BEpusdt 配置对应钱包与汇率。若提示存在未完成或待核对支付，先处理旧支付，或创建独立的新渠道；不要删除历史渠道来绕过核对。

用户在 BEpusdt 付款页面选择或切换币种、网络；商城不生成 GM Pay 式的本地支付方式列表。旧渠道升级后不会自动切换模式，历史支付和回调继续保留。原有代理成本、导入预览及独立加价修复包含在本版中。

已对照 BEpusdt v1.24.2 真实处理代码完成隔离协议测试，覆盖 23 个固定组合、6 类收银台币种、切换网络与重试；另有双模式支付/充值回调、后台桌面/手机回归及 GM Pay 回归。测试不涉及真实链上资金，实际到账需商家部署后联调。

Linux amd64 / arm64 发行包附 SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.77 bash deploy/docker-install.sh` 更新。发行发布不代表客户服务器已升级。

版本下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.77

# ZCard v1.2.90

发布日期：2026-09-28（北京时间）

## ZCard 自对接修复

- 上游地址支持站点根地址或带 `/api/supply` 的接口地址，不再重复拼接接口路径。
- 修复连接测试请求方法与上游接口不一致导致的 404；带凭据的连接测试会验证账号、签名和 IP 白名单，并返回对应供货账户余额。
- 修复 Ping 跳过鉴权导致余额无法读取的问题，区分未知余额与零余额，后台正确显示零余额。
- 修改上游地址时，在同一事务内重新加密原有凭据；无需重复填写正常凭据，重加密失败时回滚整个修改。
- 凭据无法解密或格式错误时提示重新配置，不再误报“商品、规格或账号报价不完整”；重新保存有效凭据后可重新加载目录并导入商品。

## 升级说明

本版无新增数据库迁移。请使用完整发行包同步更新服务端、后台与商城，并刷新浏览器。ZCard 自对接的上下游均应升级，余额鉴权修复需要上游同时更新。

如果旧版本修改过上游地址，且现在已经出现 `crypto: decrypt failed`，升级不会自动恢复丢失的凭据绑定。请编辑该货源，重新完整填写 API Key 和 API Secret 并保存，再重新加载商品目录；无需删除原货源或已导入商品。

本地验证覆盖两种地址及尾部斜杠、地址修改与事务回滚、损坏凭据恢复、真实 HTTP 自对接、账户鉴权与零余额，以及目录加载、导入任务、商品价格、映射和库存落库。测试使用隔离数据库与本地上游，客户线上站点仍需升级后验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.90 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已经安装或重启。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.90

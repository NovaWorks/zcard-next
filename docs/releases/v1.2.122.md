# ZCard v1.2.122

发布日期：2026-11-22

## 按购买数量确认上游库存

- 对没有数字库存、但支持数量确认接口的 ZCard 供货商品，导入时按单件检查可购性，详情显示“下单时确认库存”，不再一直停留在库存待确认。
- 创建订单时按客户实际购买数量重新核验。确认只对本次数量有效，不代表无限库存；超时、接口缺失或上游明确不可买时继续阻止付款。
- 此类商品从详情页直接购买，不进入要求明确库存数量的普通购物车。供货端与开源版需配套更新，旧供货端没有数量确认接口时仍保留原限制。

## Market 供货兼容与拒单处理

- 补齐通过标准 ZCard 货源从 Market 进货的库存核验及采购状态兼容。供货端的 fulfilled / fulfilling 分别按已交付 / 待交付处理，取消或退款后的旧回执不作为交付依据。
- 上游明确缺货、没有上游订单号且没有交付回执时，符合条件的人民币会员余额普通卡密单商品订单可退回原实付余额；保存原退款凭证，重复处理不会重复入账。
- 仅有成功的原余额付款凭证、无手续费且无其他待核对退款的订单适用自动处理。已受理、结果不明、游客、外部付款、多商品等情况继续人工核对。

## 升级说明

本版无新增数据库迁移。升级前备份数据库、配置和上传文件，保留原加密密钥，配套更新服务端、后台及内置商城并重启。独立第三方主题需适配按需库存状态。

Market 接入的萌次元规格按商品分别供货；需要额外购买资料的商品及服务套餐、订阅等尚未核实计费的类型不因此自动开放。19csn 服务商品继续使用独立规则、总价报价和会员余额订单流程。

提供 Linux amd64 / arm64 完整程序、SHA256 校验、ED25519 签名更新清单，以及双架构 Docker 应用和配套更新器。公开发布不代表客户生产站点已经升级；真实上游付费采购、交付及退款仍需分别验收。

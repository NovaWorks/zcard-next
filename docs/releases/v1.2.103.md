# ZCard v1.2.103

发布日期：2026-10-01

## 分类与商品删除

- 删除父分类时，事务内同时删除全部子分类并移除其中商品，包括上架、隐藏、下架和锁定商品；批量删除自动合并父子分类，避免重复请求，失败项保留供重试。
- 商品删除立即从后台、商城和供货目录移除，释放分类，关闭自动上下架，清理购物车、运营设置、货源映射和供货定价，并停用关联抽奖奖品。
- 锁定商品、待付款和发货中的订单不再阻止商品删除；保留订单商品快照、已有交付内容、取货、退款及账务记录，已有订单继续处理，账户余额不变。
- 保留已有订单所需的库存和历史商品记录；没有未完成订单时，剩余可售卡密停用。归档商品无法通过上下架或自动同步重新恢复。
- 删除界面统一为“确认删除（保留订单）”；旧客户端请求同时删除订单时，服务端明确拒绝，避免误删历史记录。

## MySQL 并发保护

- 修复 MySQL 无变化更新返回零行导致商品或分类被误判为不存在的问题，删除与供货定价使用加锁读取确认当前状态。
- 等待并发事务后读取已提交状态，避免对已删除商品、分类新增专属价；保留 SQLite 写锁保护和租户隔离。

## 接码渠道导入

- 上游接码能力改用多个 capabilities 参数传递，修复部分上游无法识别能力列表、接码商品目录无法正常导入的问题。
- 货源渠道桌面列表新增直接“导入商品”入口；只有一个接码商品时自动展开分类并选中可导入商品，移动端继续使用操作菜单。

## 升级与验证

本版无新增数据库迁移。请备份数据库、配置及上传文件，保留原加密密钥，更新完整发行包并刷新浏览器。从旧版本升级仍需执行已有累积迁移。

删除父分类会同时删除全部子分类和其中商品，操作前请核对删除范围；订单快照、交付、退款及账务记录继续保留。

验证覆盖 Go 全量测试、受影响模块 go vet 与 race 回归、MySQL / PostgreSQL 删除及定价集成测试、后台类型检查及生产构建、fullstack 内嵌资源检查，以及 390px / 1440px 商品删除、分类批量删除和接码导入页面回归。页面回归使用模拟接口，不代表客户生产数据或真实上游已验收。

发行包提供 Linux amd64 / arm64、SHA256 校验和、ED25519 签名清单及 Docker 镜像，继续支持 Docker 后台在线更新。版本发布不代表客户站点已自动升级。

# ZCard v1.2.76

发布日期：2026-09-24

## 修复导入商品预览成本

- 补齐 v1.2.75 遗漏的渠道管理导入预览：ACG 商品按当前账号获取单件报价，逐规格查询，显示账号实际适用的代理成本，不再展示目录原价作为成本。
- 预览与商品管理使用相同成本计算口径：账号单件报价按渠道汇率换算，不包含商品或渠道加价，也不使用售价取整；多规格商品注明最低成本。
- 展开分类后按需查询，同时最多查询两件商品，目录加载不等待全量报价；增加查询中、查询失败、单件重试和刷新成本入口，失败不回退原价。
- 关闭弹窗或切换渠道时取消旧报价，忽略过期响应；重试和刷新保留商品勾选，刷新成本仅更新预览，不写入商品价格。
- 报价期间账号或汇率变更时拒绝返回旧结果。正式导入仍重新获取账号报价，沿用 v1.2.75 已保存的商品加价规则。

## 升级说明

本版无新增数据库迁移。升级后刷新后台，再进入“渠道管理 → 导入商品”，展开分类查看“成本”；多规格商品显示“起”。如上游报价失败，可点击该商品“重试”。

商品管理显示的是最近导入/同步保存的成本，导入预览显示本次查询的成本；上游报价变化后，需要同步商品才能更新已保存成本。预览不会自动改写现有商品售价或加价规则。历史商品缺失加价规则的处理方式保持 v1.2.75 的说明。

已验证成本与实际导入一致、汇率不叠加加价、失败重试、旧响应隔离及桌面/手机交互。本地测试使用隔离数据，真实上游账号仍以部署后的接口结果为准。

Linux amd64 / arm64 发行包附 SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.76 bash deploy/docker-install.sh` 更新。发行发布不代表客户服务器已安装升级。

版本下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.76

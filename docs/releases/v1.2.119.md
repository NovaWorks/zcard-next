# ZCard v1.2.119

发布日期：2026-11-20

## 萌次元上游采购

- 后台渠道新增“萌次元 mcy-shop”，使用上游 OpenApi 插件提供的对接 ID、密钥和网站根地址连接。
- 支持拉取分类、商品说明、图片和多 SKU，逐规格读取账号报价，按买家所选 SKU 查询库存、检查购买数量并提交采购。
- 可同步受支持的标量购买控件及校验规则，采购时转发客户填写资料。多选数组控件暂不支持。
- 文字库存或无效库存保留为未知，不当作无限库存；目录仅代表可见商品，不据此确认上游永久删除。上游未返回币种代码，需按其实际币种配置汇率。

## 向萌次元供货

- 下游账号和前台对接申请新增萌次元协议，继续使用账号审核、独立余额、供货定价和 IP 白名单。
- 萌次元站可安装“异次元 V3 / MCYShopV3”货源插件，填写本站根地址及下发的账号密钥，拉取商品并下单；补齐该插件调用的旧版库存和库存预检接口。
- 同时提供 `/plugin/open-api/` 兼容接口，覆盖连接、目录、单品、SKU 库存、数量预检、报价和同步下单。相同账号下重复提交同一单号只扣款一次，商品和数量冲突会被拒绝。
- 对外供货沿用现有范围：人民币、无本地 SKU 的本地卡密商品。上游多 SKU 导入不代表对外供货已支持多规格或上游代发。

## 采购结果核对

- 萌次元下单后遇到超时、断连、响应异常、空交付、发货占位文案或数量不符时，转人工核对原上游订单，不自动再次采购或退款。
- 已核实的客户端契约未提供独立查单、订单列表、退款或回调接口，本版不将这些能力标记为可用。

## 升级与验证

- 本版包含 MySQL 账号协议 ENUM 扩展迁移，正常启动时自动应用；SQLite、PostgreSQL 的对应文本列无需新增 DDL。升级前备份数据库、配置和上传文件，保留原加密密钥，配套更新服务端、后台和商城。
- GitHub 提供 Linux amd64 / arm64 程序、SHA256 校验及签名更新清单；Docker 应用和配套更新器提供相同两种架构，版本为 `v1.2.119`。
- 本地验证覆盖后端全量测试、MySQL 实际迁移及新协议下单、双方 HTTP 契约互通、PHP 签名向量、报价、库存、幂等扣款及人工处理分流，前后台类型检查、商城翻译检查和生产构建通过。
- 尚未连接实际运营中的萌次元站安装其 OpenApi 插件联调；发布不代表客户生产站点已升级或真实交易已验收。频道公告由用户手动发送。

对接配置说明：`docs/features/mcy-shop.md`。

# ZCard v1.2.121

发布日期：2026-11-21

## 19csn 服务渠道

- 后台「渠道 → 货源渠道」新增「19csn（服务渠道）」，填写网站根地址或 `/api/v2` 地址及 API Key，即可测试连接、读取余额和导入服务。
- 支持普通服务单次投放和自定义评论，按上游数量范围及购买规则填写资料、确认整单报价，再使用会员余额购买。评论保留顺序和重复内容，每行一条，不允许空行。
- 订单显示服务进度；按当前服务能力提供取消和补量申请，保存供应商补量 ID 并继续查询结果。取消申请受理不代表已取消或退款到账。
- 测试连接按上游实际账号币种显示余额。供应商小数费率保留到整单换汇，避免先按每份成本取整或重复换汇；前台不公开上游成本和凭据。

## 提交与结算保护

- 采购、取消和补量先持久化提交标记。上游没有公开订单幂等键，超时、断连或无效回执会进入待核对状态，不自动重复发出可能已受理的请求。
- 服务规则或汇率配置变化时，在向上游提交前拒绝过期报价。上游不提供报价锁定或最高扣款参数，后续异常金额仍需核对。
- 部分完成、取消和失败不按剩余数量推断退款金额；仅显示已确认退款，未取得明确金额凭据时保留待核对状态。
- 套餐、订阅和多次循环投放暂不开放，需核实相应计费和预算规则后扩展。

## 配置与验证

真实账号只读联调确认币种为 CNY，该账号汇率填 1；目录返回 191 项，其中普通服务 175 项、自定义评论 8 项为当前已支持类型。服务数量及规则以上游实时返回为准。已经验证真实适配器、隔离数据库导入、前台隐藏供货费率及本地人民币报价，尚未执行真实采购、取消、补量或扣款。

本地后端全量测试、go vet、相关竞态检查、前后台类型检查、商城翻译及金额检查、后台生产构建，以及 1440px / 390px 渠道页面回归通过。

## 升级说明

本版无新增数据库迁移。请备份数据库、配置和上传文件，保留原加密密钥，配套更新程序、后台和内置商城后重启。使用服务购买前请确认上游余额和本站余额支付配置。

提供 Linux amd64 / arm64 程序、签名更新清单，以及 `nealbaker/zcard-next:v1.2.121` 和 `nealbaker/zcard-updater:v1.2.121` 配套镜像。

萌次元未知库存的购买限制仍沿用当前行为，之前讨论的按购买数量预检方案未纳入本版。频道公告由用户手动发送；版本发布不代表客户生产站点已经升级或完成真实交易验收。

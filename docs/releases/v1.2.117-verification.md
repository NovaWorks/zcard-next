## CI 边界

[本次发行提交的 CI](https://github.com/NovaWorks/zcard-next/actions/runs/44541093203) 有 4 项通过：部署与干净 Docker、前端金额、商城首屏与配置恢复、MySQL/PG 集成。

两项失败为既有问题，不宣称 CI 全绿：

- server 生成物检查通过，随后格式检查命中 `data_lowstock_test.go`、`data_points_test.go`、`data_reseller_journey_test.go`、`data_pricing_test.go`、`pricing_test.go`、`data_withdraw_test.go` 六个既有测试文件；这些文件本版均未改动。本地全量测试与静态检查已独立执行通过。

重复的自动 Release 作业已取消，避免与经独立校验的本地发行产物竞争。

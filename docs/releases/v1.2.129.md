# ZCard v1.2.129

发布日期：2026-11-24

## 商品排序直接编辑与批量保存

- 商品管理列表新增“排序”输入框，无需逐件打开商品编辑页。可连续调整多件商品，再点击“保存排序”统一生效；数字越小越靠前。
- 支持先筛选分类再调整，翻页或切换筛选时保留本次排序修改，并提示其他页或筛选外待保存的商品数量。每次最多保存 1000 件。
- 保存失败保留输入，支持重试或取消修改；离开页面前提示尚未保存的排序。锁定商品不能编辑，提交前被锁定的商品会跳过，并显示结果。
- 排序保存使用独立接口，不改动商品价格、成本、积分价、库存展示、上下架及自动管理设置。多人同时调整产生冲突时整批回滚，避免覆盖他人的排序或只保存一部分。
- 手机窄屏取消操作列固定，避免遮挡排序输入框。

## 排序范围与升级说明

修改的是商品通用排序，可在全部商品和分类商品列表的商城综合排序中生效。分类内置顶仍优先；买家主动选择价格、销量或最新排序时沿用对应规则。

本版无新增数据库迁移。更新服务端和配套后台后刷新页面即可使用；已有商品排序值保持不变。升级前按现有流程备份数据库、配置与上传文件，并保留原加密密钥。

提供 Linux amd64 / arm64 完整程序、签名更新清单、SHA256 校验及配套 Docker 镜像。独立付费主题不包含在主程序发行包中。

# ZCard v1.2.81

发布日期：2026-09-25

## 导入全选与关键词分类

- 导入窗口支持全选全部商品、全选搜索结果、仅选未导入和清空选择；切换搜索保留已选商品，自动跳过锁定商品。
- 可按商品名称关键词自动分配分类，支持排除词、任意或全部匹配、规则优先级，以及保存本货源规则。
- 支持单件手动指定分类；批量指定默认只影响本次选择，保存整个上游分类映射需明确选择。
- 已有商品可从商品管理按关键词分类，先预览再应用，跳过锁定和受保护分类；预览后发生变化的商品提示冲突并跳过。

## 对接商品可使用自己的卡密和重复发货

- 无需重新创建商品，可按规格选择每单向上游采购、使用自己的单次卡密，或重复发货。
- 重复发货支持手动填写内容、选择本商品同规格成功且未退款的历史采购内容，或首次付款后自动采购一次，后续订单使用已保存内容。
- 支持有效期、最多发放次数、暂停和恢复；重复发货规格每笔购买限一份。内容换版后，历史订单保留原交付内容。
- 并发下单只发起一次共享采购，首位买家退款不影响其他订单取货。网络结果不明确时等待核查原采购，不自动再次下单。
- 已配置本地或重复发货的商品由商家维护，跳过上游资料、价格、库存和上下架同步；本地卡密不足不会自动转向上游购买。

## 交付保护与操作体验

- 发货设置按商品、规格和站点隔离，遵守商品锁定；普通编辑接口不能绕过来源设置。
- 含客户专属填写字段的商品不允许重复发货。共享内容加密保存，管理接口不返回明文，操作日志脱敏。
- 补齐采购回调提前到达、进程重启恢复、发放次数并发校验，以及过期和暂停处理；采购异常订单等待商家处理，不自动退混合订单的整单。
- 首次共享采购成本只记录一次，复用订单不重复计成本；自填内容没有采购凭据时按成本未完整记录处理。
- 电脑和手机均支持分类预览、按规格设置和暂停操作；保存失败保留填写内容。

## 升级说明

本版包含 SQLite / MySQL / PostgreSQL 数据库迁移，新增共享发货来源及订单引用、分类保护字段。升级前备份数据库、配置和上传文件，建议低峰升级并检查迁移日志。后台、服务端和商城需一起更新，完整 Linux amd64 / arm64 包已内置前端；第三方主题需适配重复发货的购买数量限制。

旧商品和订单保持原发货方式，重复发货须由商家明确开启。分类保护从本版开始记录，升级前的手工分类无法可靠还原，首次批量分类务必检查预览。既有商品关键词分类一次最多 1000 件。

配置本地或重复发货的商品不再通过旧同步供货购买接口对外销售；商城购买流程支持。混合规格商品的其他上游规格，下单时仍校验上游库存。共享内容失效、到期或采购待核实时，不会自动购买替代内容，需在发货设置中处理。

已完成后端全量测试、采购竞态检查、三种数据库迁移与 MySQL/PostgreSQL 并发验证、前后端类型检查及生产构建、电脑和手机导入/分类/发货设置回归。采购测试使用隔离网关，真实上游采购仍需部署后验收；版本发布不代表客户站点已升级。

发行包附 SHA256 校验和 ED25519 签名更新清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.81 bash deploy/docker-install.sh` 更新。

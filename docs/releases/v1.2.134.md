# ZCard v1.2.134

发布日期：2026-11-28

本版现作为验证版保留。请使用 [v1.2.135](https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.135)，补齐并发提交等待保护。

修复采购自动重试中断、ACG 单件商品堵住整批同步，以及旧商品直达链接缺少编号的问题。

- 采购轮询任务按实际退避时间入队，后续轮询使用独立任务标识，不再因正在执行的任务 ID 冲突而丢失续排。
- 每 15 秒扫描到期采购单，包含明确可重试的 pending 单；未到期记录不占扫描名额，慢查询不会阻塞整个巡检批次。
- 明确未受理的临时提交失败，使用原采购单、原请求号、原商品规格及数量重试；重复执行不会再次采购。订单取消、关闭或正在退款时停止重试。超时、断线、重复请求及结果不确定的单据继续保留人工核对。
- ACG 单品读取返回 code=0“服务器频繁请联系客服支持”时，保留该商品原数据并继续处理后面的健康商品，任务结果列出失败商品；不会把读取失败误当下架或无规格商品。真实 HTTP 429、认证失败及网关拦截继续暂停读取。
- 状态和价格同步会为已绑定的旧商品补齐缺失的数字 page_id，无需重新采集。已有有效编号和历史订单来源快照保持原值。
- 修复同步失败后显示已安排自动重试，但执行上下文结束导致重试被提前取消的问题。

本版无新增数据库迁移。更新完整程序并重启后，待处理且到期的采购任务由巡检恢复；已转人工、结果未知或已人工补发的订单不会自动重买，请先核对原上游订单。旧商品链接可执行一次状态或价格同步补齐。原有真实限流冷却仍需等待结束。

# ZCard v1.2.94

发布日期：2026-09-30（北京时间）

## 新增 UPAY PRO 支付渠道

- 新增独立 UPAY PRO 原生支付驱动，支持 USDT、USDC 多链及 TRX，共 10 种币种与网络组合；每个渠道固定一种组合，可新增多个渠道供顾客选择。
- 支持商品付款、会员余额充值和供货账户充值，沿用手续费、费用承担方、推荐、排序及支付用途设置；供货充值完成后返回供货账户页。
- 后台提供网关地址、通信密钥、收款网络和本地支付期限配置；密钥加密保存、不回显，编辑留空保留原值。
- 下单以含顾客手续费的人民币金额计价，实际链上金额由网关换算；兼容上游实际使用的数值签名格式与毫秒过期时间。

## 支付与到账保护

- 回调验签并核对渠道实例、商户支付单号、网关交易号和原始人民币金额，仅成功状态入账；重复通知不重复发货或充值。
- 重复点击复用原支付尝试和收银台地址，并发请求不会重复下单，重试不会延长本地支付期限。
- UPAY PRO 对已支付或已过期订单不保证重复创建幂等；请求结果不确定时阻止自动重复建单，并显示原商户单号供后台核对。
- 支持回调先于下单响应、进程中断后的待核对记录，以及未知结果后有效回调恢复到账。
- 订单关闭或重复收款后保留到账记录并进入待核对，不再次发货或充值；渠道停用、删除后继续处理历史回调，有未确认支付时保护原凭据。

## 升级说明

本版无新增数据库迁移。从更早版本升级仍会执行未应用的历史迁移，请先备份数据库、配置及上传文件，使用完整发行包同步更新服务端、后台和默认商城，完成后刷新浏览器。

在支付渠道添加 UPAY PRO，填写服务根地址和通信密钥，并确认网关已配置对应网络的钱包、汇率及有效期。本站须提供公网可访问的回调地址。原有 GM Pay 和 BEpusdt 保持独立。

UPAY PRO 的公开查单仅返回状态，不含完整到账凭据，本接入以验签回调确认到账；漏通知需在网关核对并重新通知。上游没有原路退款 API，链上退款仍需人工处理。独立第三方主题需确认能展示后端新增渠道并处理跳转支付。

已通过后端全量测试、支付并发检测、前后台类型检查、后台构建，以及桌面和手机配置页面验证。支付测试使用本地模拟网关，未进行真实钱包转账验收。

发行包内置后台与默认商城，提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名清单。Docker 用户可使用 `ZCARD_VERSION=v1.2.94 bash deploy/docker-install.sh` 更新。版本发布不代表客户站点已自动升级。

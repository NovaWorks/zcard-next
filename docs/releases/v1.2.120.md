# ZCard v1.2.120

发布日期：2026-11-21

## 调整余额

- 修复后台调整余额成功后弹窗仍停留的问题。成功后立即关闭弹窗并刷新用户列表余额，不再等待额外的余额查询。
- 提交期间阻止重复点击及关闭弹窗；调整失败保留金额和原因，便于核对后重试。

## 会员价格

- 修复后台指定会员等级后，商城商品列表、详情、规格和购物车仍显示原价的问题。展示价格复用下单的会员折扣与商品组规则，按整数分计算。
- 客户保持原登录状态即可读取新价格；修改或取消人工等级后，下次读取商品和购物车价格即时生效。隐藏等级也按其实际折扣计算，不公开等级资料。
- 商品组禁止叠加时取更优惠的一档，允许叠加时按原结算规则计算；分站加价不参与会员折扣。已有订单保留原成交金额。
- 会员价格响应禁止共享缓存，避免不同客户之间复用价格。动态报价服务和接码商品继续沿用自身报价规则。

## 萌次元与规格库存

- 萌次元商品参考库存改为汇总各规格实时库存，未知库存保持待确认。
- 商品详情按选中的规格独立读取并短暂缓存库存；某个规格售罄或库存未知时，不再借用其他规格或商品汇总库存。

## 升级与验证

本版无新增数据库迁移。请备份数据、保留原加密密钥，更新服务端、后台及内置商城后重启。独立主题需重新读取服务端商品、规格及购物车价格；频道公告由用户手动发送。

后端全量测试、go vet、前后台类型检查、商城翻译检查和生产构建通过。桌面与手机浏览器覆盖调账失败保留、连续点击防重、成功立即关闭、列表余额刷新及会员等级设置。会员价格回归覆盖同一登录状态下的改级、撤销、隐藏等级、SKU 继承价、商品组取优与叠加，并与实际下单报价核对。

发行包提供 Linux amd64 / arm64 程序、签名更新清单和配套 Docker 镜像。发布不代表客户生产站点已部署或真实交易已验收。

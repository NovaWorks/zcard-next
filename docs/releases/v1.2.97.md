# ZCard v1.2.97

发布日期：2026-09-30

## 通用短信接码客户端（默认关闭）

- 新增基于 ZCard 公开供货协议的接码客户端，商品、会话与操作均按通用能力处理。供货端新增符合 v1 契约的来源时，客户端通过刷新目录导入；客户端不直接连接第三方短信平台。
- 商品导入支持按页浏览、跳页、搜索本页和折叠分类。每页保存独立快照，同名分类按父级路径区分，大目录不再依赖一次全量加载。
- 接码订单限登录会员、CNY 余额付款、单件独立订单，暂不支持游客、外部支付、SKU、购物车、优惠券、积分和营销返佣。下单及付款前检查供货账号、能力、实时库存、余额和价格上限。
- 后台持久保存固定采购意图，未知结果使用原请求重试；关闭浏览器或服务重启后继续查询。账号和订单租约防止并发重复处理，限流按 Retry-After 退避，异常订单隔离核对。
- 默认商城订单页展示号码、验证码、短信正文及租期，支持独立复制和按当前能力取消/完成；只有正文、带前导零或字母的验证码均保留原内容。短信内容加密保存，接口校验会员及租户身份，不进入普通卡密通知。
- 取消/完成使用独立固定操作号恢复。只有明确未扣款的拒绝回执，或核对过全额供货退款凭证后，才幂等退还零售剩余实付；供货成本不作为买家退款金额。后台新增接码任务诊断及带审计原因的原任务恢复。

## 升级与启用

本版包含 SQLite / MySQL / PostgreSQL 增量迁移，新增接码任务、操作记录和账号租约，以及商品、订单项交付类型字段。普通卡密商品默认为 `card`。升级前备份数据库、配置和上传文件，保留原加密主密钥，同步更新服务端、后台及默认商城，检查迁移日志并刷新浏览器。

**接码新购默认关闭。** 只有服务进程配置 `ZCARD_SMS_SALES_ENABLED=true` 并重启才可启用。关闭新购不停止已有接码任务、查单和退款恢复。独立第三方主题需要自行适配接码订单页面。

本版提供默认关闭的客户端功能。已执行本地公开契约 fixture、数据库账务与浏览器验证；尚未完成 OS-5 真实收码、真实资金闭环及计划 13.7 的固定安装包双供应商准入验收。供货端的通用化和真实新来源准入需分别完成，不能将本版发布视为已经完成真实双供应商验收；完成隔离环境验收后再开放销售。

按本地构建流程提供内置后台和默认商城的 Linux amd64 / arm64 程序、Docker 双架构镜像、SHA256SUMS、ED25519 签名更新清单及 Docker 镜像清单，本次不运行 CI。继续支持官方 Compose 后台在线更新；部署命令为 `ZCARD_VERSION=v1.2.97 bash deploy/docker-install.sh --online`。版本发布不会自动升级客户站点。

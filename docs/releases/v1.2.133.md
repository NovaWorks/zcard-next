# ZCard v1.2.133

发布日期：2026-11-28

补齐 Telegram 工单提醒，修复连续回复被错误去重后漏通知的问题。

- 系统设置 → 工单 / TG通知 新增“主站工单通知”独立开关，可选择新工单、客户追加回复、工单加急，复用已有 Bot、个人或管理群以及群话题。
- 工单与订单、低库存提醒分别控制。只开启工单提醒时，也能正常发送测试消息、查看投递记录和重试失败消息。
- 每条客户追问、客服公开回复按消息 ID 独立生成事件，同一事件重复处理不会重复排队。客服自己的回复和内部备注不推给商家。
- 工单创建、公开回复及加急操作与通知事件一起提交；通知事件写入失败时整体回滚，加急费用不会单独扣除。
- 通知提供工单号、类型、当前状态、优先级及后台入口。打开链接并登录后直接查看对应工单，正文、附件和游客联系方式保留在后台。
- 主站提醒继续隔离分站事件；停用通知或移除原接收位置后，尚未发送的提醒不会改投其他群或话题。

本版无新增数据库迁移。更新完整程序并重启后，在“系统设置 → 工单 / TG通知”打开“主站工单通知”，确认事件选项后保存。工单通知默认关闭，已有 Bot 和接收位置保留；升级不会补发旧工单事件。

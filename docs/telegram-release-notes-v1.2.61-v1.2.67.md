# ZCard 版本更新公告｜Telegram 发布版

历史记录核对日期：2026-09-22；新增公告更新日期：2026-09-24。本文件整理 **Go 重写版 zcard-next**。频道原有 `v1.12.60` 公告属于旧 PHP 系列，不能将两个版本号等同；本文仅记录 Go 系列；历史频道发送状态保留在文末。

本文整理 **v1.2.60 之后**的全部正式版本，即 **v1.2.61—v1.2.72，共 12 条**。此历史汇总截止 v1.2.72，新增公告由用户自行复制到频道；历史版本发送记录见文末。依据 GitHub Releases 与 `server/CHANGELOG.json` 整理，发布日期统一为北京时间（UTC+8）。

每个代码块是一条完整公告，可直接点击复制后粘贴到 Telegram；不需要复制版本小标题、分隔线或本段说明。按下列顺序逐条发布到「ZCard 众卡开源发卡系统频道」@ZCardGroup。

这些是历史版本更新回顾，实际升级可直接选择最新正式版，无需为了公告顺序逐个安装。各发行包均提供 Linux amd64 / arm64、SHA256 校验和 ED25519 签名清单。升级前请备份数据库、配置与上传文件；独立安装的第三方主题需另行更新适配。
